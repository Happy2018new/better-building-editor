# 萤火虫灌木动画的冻结原生输入

来源为网易基岩版 `3.10.0.420447` 的 `data/resource_packs/vanilla`。`source.json` 保存原生相对路径、长度和 SHA256。四份原生文件共30,951字节：完整80条动画声明、灌木静态图片、10帧亮点图片及物品 carried 图片。

这些文件仅供宿主生成器 `tools/generate_firefly_bush_animation.py` 使用，游戏不导入或读取本目录。生成器保留完整原版动画列表，然后保留本地声明，最后追加项目条目；合成图片的每帧透明轮廓必须等于 carried 轮廓，并与既有居中几何 profile 的来源指纹相符。

动画来源版本与现有方块表／居中几何 profile 的来源版本分别记录，不把这组图片对照扩展为整个状态表或原生粒子资格。具体冷启动、连续采集、已集成资源指纹和未关闭范围见 [专项记录](../../../docs/FIREFLY_BUSH_R23.md)。
