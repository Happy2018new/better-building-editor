# 建筑生物群系染色

现代化投影现在为每个建筑配置保存一个独立的生物群系染色预设。它只改变编辑器预览和客户端投影中草、树叶等使用生物群系颜色的材质，不修改世界的生物群系，也不会同步给其他玩家。

在工作台打开“场景 → 外观”或“投影 → 显示”，展开“生物群系染色”即可选择预设。目录保留 13 种不同的草木配色：草原、森林、白桦林、针叶林、沼泽、红树林沼泽、丛林、干燥群系、雪原、苍白花园、樱花树林、恶地和黑森林。沙漠和热带草原的草、叶颜色均相同，合并为“干燥群系”一个按钮；旧建筑中的两个名称仍可读取。

“使用当前位置的群系”会在点击时读取玩家所在位置一次，并根据草、树叶两组颜色匹配预设。映射涵盖 Bedrock 1.21.120 原版资料中的 87 个群系名称；相近的海洋、河流、山地、洞穴和丘陵变种共用代表色，苍白花园等明显不同的颜色保留独立预设。未支持的自定义群系会保留当前选择并显示提示。预览和已生成的投影共用同一设置，切换时只更新材质参数，不重新提交方块模型。

苍白花园的草色 `778272`、叶色 `878D76`，樱花树林的草/叶色 `B6DB61`，恶地的草色 `90814D`、叶色 `AEA42A`，均核对原版 `resource_packs/vanilla/biomes/*.client_biome.json` 的 `minecraft:grass_appearance` / `minecraft:foliage_appearance`。黑森林遵循原版 `grass_is_shaded` 外观，以游戏草侧面图集的遮阴草色 `507A32` 配合森林叶色 `59AE30`。这些颜色代表草木染色，不包含天空、雾和环境光。

设置随小型配置、64×128×64 大型配置、本地建筑库、分块存档以及分享/导入数据保存。没有该字段的旧配置按草原处理。建筑的方块 ID、状态和附加值仍按原数据保存；白色石英、玻璃和羊毛等不使用生物群系染色的材质不会被预设统一改色。

渲染使用独立命名的 `modern_projection_biome_blocks` 顶点/片元着色器。客户端预览通过透明 1 像素控件传递预设索引，世界投影通过 actor extra uniform 传递索引；两条路径都保留原有透明度、网格和亮度控制。原版季节材质的 foliage/grass 颜色改为固定预设采样，避免物品目录或其他 PaperDoll 绘制遗留的纹理绑定使树叶变红。

在雪原普通世界中，原生树叶转换成投影几何体时会出现叶面丢失；短草、蕨、高草和大型蕨也会出现面片缺失。投影使用隐藏的叶子方块和草本交叉面片代理来保留原版纹理与草木染色；建筑数据、放置方块与导出内容仍保存原始方块。樱花、杜鹃和苍白橡木等固定颜色的叶子不使用群系渐变图。

草本代理的模型坐标需考虑网易合并几何体时的 X 轴反转：方块范围对应模型 X=-16..0、Y/Z=0..16，交叉面旋转中心为 `(-8, 8, 8)`，面片原点为 `(-16, 0, 8)`。不能直接套用以 X/Z=0 为中心的实体模型坐标，也不能将 X、Z 都移到 +8。正面和侧面正交视角应分别检查草本是否在底座中央；高草和大型蕨上下两段使用同一坐标约定。UI 和世界投影共用这些模型，世界投影的整体坐标变换无需调整。

17 个内部代理在方块 description 中使用 `register_to_creative_menu: false`，不出现在创造栏或其搜索结果中；`register_to_create_menu` 是物品模板的字段，不能用于隐藏这些方块。编辑器方块目录仍显式过滤内部代理 ID。

当前建筑模型只保存每个位置的前景方块，渲染调色板的 `extra` 为空。含水、含雪的背景层不纳入本轮支持范围；放置、擦除、分享及存档格式继续使用现有单层模型，不承诺还原雪和草共占同一位置的组合。
