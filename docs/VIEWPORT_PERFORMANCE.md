## 放置连续性与大视图

`verify_preview_frames.py` 将游戏确认为前台后，仅截取三维区域；用真实鼠标连续放置四格，按图像中的模型像素覆盖检测建筑消失，并保存最少覆盖帧及相邻帧供视觉核查。

- 去掉重复提交后的单预览版本：154 个采样画面中有 9 个模型消失样本，最低模型像素数为 4。
- 最终双缓冲版本：约 3 秒采样 92 个画面，0 个消失样本；初始模型像素 6113，最低 6111。四次点击均实际执行，最终命中坐标升至 Y14。
- 前后世界光照会变化，所以覆盖阈值使用每次采样自身基线；不会把两次像素绝对数量当作画质指标。这种采样验证不等于覆盖游戏的每个输出帧，也不保证任意大建筑和慢速设备的 GPU 就绪时间。
- 1920×1080 的专注视图面积为普通视图的 2.3073 倍，原生 Scene/指针/两个预览控件在展开和还原过程中保持相同 ID。20:9、4:3、16:10、16:9 下的场景、属性面板边界及三维拾取共 44 项检查通过。

本轮通过 40 项单元测试、19 项三维/控件交互检查、6 项真实鼠标检查、16 项原有 UI 回归、8 项专注编辑功能检查。13 个业务 Python 文件通过 MCDK 解析检查；保留函数长度、参数数量和现有 sys 导入建议。
