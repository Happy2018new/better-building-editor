# 现代化投影 · 使用说明

这是面向网易我的世界基岩版 ModSDK 的建筑编辑工作台，附带可合成的投影测绘器与投影终端。

## 开始使用

1. 手持 **投影终端** 右键使用，或点击屏幕上的 **投影工作台** 按钮。首次工作台中有可编辑的庭院示例；进入世界时不会自动打开界面。
2. 按 **Esc** 或右上角叉号关闭工作台，再次使用投影终端重新打开；有确认、重命名或方块目录弹窗时，Esc 先关闭弹窗。
3. 可以直接编辑庭院示例，或在 **建筑库** 新建空白草稿。手持 **投影测绘器** 依次右键两个方块，选完后左键导入；触屏直接轻触两个方块，再点击 **导入选区**。导入在建筑库新建配置，保留当前草稿；再次选点会开始新的选区。测绘范围显示金色线框、环绕晶体和明暗、大小变化的星光，只有本人可见；不再绘制白色网格或白色面。点击选点时，发光碎片逐片出现并旋转聚拢。详细配方和限制见 [世界工具](WORLD_TOOLS_71.md)，历史效果说明见 [星尘测绘](SURVEY_STARDUST_72.md)，当前实现与验证见 [项目交接](CONVERSATION_HANDOFF.md)。
4. 左侧选工具，右侧的 **当前选区** 与三维 **框选** 使用同一份范围。先框选或展开 **坐标设置** 修改起终点，再设置主/副材质、方块条件和工具参数，点击 **执行**。所有草稿操作都限制在当前文档长方体内。
5. **建筑库**中可以修改名称、保存多个配置、载入、重命名、删除，或指定 X/Y/Z 尺寸新建空白草稿。
6. **投影**中设置世界原点、不透明度、图层和缺失过滤，点击 **更新 / 生成投影**。关闭工作台即可在世界中照着投影搭建。配置保存在本机全局库，切换世界仍可使用。

投影设置 **显示** 页的 **炫彩范围框** 默认开启，用连续流动的彩色棱线标记整份建筑配置的长方体边界，包含内部空气区域。点击可即时隐藏或显示，选择会保存在本机；关闭投影和切换维度时一起移除。下方 **炫彩流动速度** 与 **图层 → 炫彩流动速度** 共享设置，开启“减少动态效果”后保持静态彩色。外框亮度独立于昼夜和建筑投影的不透明度，真实世界方块仍会遮挡其后方棱线。

## 工作台

- 点击场景右上角 **展开视图** 进入专注编辑：收起工具箱、分类栏和页面页签，让场景使用大部分窗口。**还原视图** 返回完整工作台；相机角度、缩放、编辑模式和草稿都会保留。
- 专注编辑中仍可保存、撤销/重做、切换完整/切面/单层、直接编辑和调整 Y 高度；点击 **材质与属性** 可随时展开右侧参数、图层与历史面板，再次点击收起。场景标题下显示当前主材质。
- 三维视图使用原生方块几何体。拖动连续控制水平和俯仰角，松手有短暂惯性；左右转、正视、俯视和缩放会平滑过渡；复位直接恢复默认全景。鼠标停在视图内时，滚轮围绕鼠标指向的位置缩放，便于持续观察同一处细节；最小为 25%，没有预设放大上限。视图左下的 **左移 / 右移 / 上移 / 下移** 按当前画面方向移动观察位置，建筑相应朝反方向移动。六向导航与切面均有文字和图标，窄视图自动分为两行。
- **前移 / 后移** 沿当前视线移动观察深度，场景左上角显示 **视线已深入 N 格**；后退到外部时隐藏提示。它不改变缩放倍率，通过原生模型深度和视线裁剪显示封闭建筑内部，不重建几何体。滚轮和倍率按钮控制放大、缩小。带房屋图标的 **复位** 按钮恢复角度、缩放、平移及观察深度。
- 场景上方统一提供 **完整 / 切面 / 单层**，始终使用同一个三维视口。完整显示所有可见层；切面显示 Y 高度和下方；单层只显示 Y 高度。上方唯一一组 **Y 输入框和 − / +** 控制当前高度，标签随模式显示 **网格 Y / 切面 Y / 单层 Y**。完整模式下 Y 只移动工作网格。比如石英建筑底部在 Y=1，网格也设为 Y=1 时才与其底边共面；Y=0 的网格在建筑下方一格。
- 所有尺寸都直接显示**整栋建筑**，最多 64×128×64。底层按 16³ 独立更新模型，界面不需要切换分块。实际方块和网格均保留原始精度，不降采样。
- 点选目标后点击 **定位选中**，将目标移到视口中心，并放大到每格 20 设计像素，整栋建筑仍保留。近距离拖动围绕按下的表面位置旋转，避免远离整栋中心的细节大幅甩动；倍率很高时会降低旋转灵敏度。**复位** 一次清除局部旋转中心、平移、缩放、惯性和待执行的镜头移动，恢复默认全景。
- 每个 16³ 区域独立提交原生模型，放置和删除只更新受影响块及必要邻块；每块双缓冲在上传时保留已有画面。撤销优先复用上一版模型，每次放置仍单独保留撤销。统计与历史在停止连续操作后合并刷新。跨模型玻璃遮挡仍有原生排序限制；保留原材质。首次大建筑生成显示进度，镜头移动不重新生成模型。
- 三维视图下方提供 **浏览、选取、放置、换材质、擦除、吸管、框选**。浏览点击定位单格；选取选择单格；换材质只替换点击位置的方块，不新增相邻方块；吸管读取主材质；框选依次点击两个角点。所有模式共用一份正式选区；独立的鼠标候选框不作为批量工具的作用范围。
- **正式选区**：单格选取和长方体框选共用一份选区。PC 用蓝框表示已选内容；触屏的单格选区和长方体区域统一使用炫彩框。点击选取立即更新，批量工具使用正式选区；改变颜色不改变选取、放置或撤销逻辑。蓝框与炫彩框的线宽一致。
- **PC 鼠标预览**：浏览、选取、放置、换材质、擦除、吸管和框选模式都有彩色正方体目标框，可与已提交的蓝框同时显示。框选第一点后，只显示起点到鼠标目标的炫彩长方体；确定第二点后恢复蓝色区域框和独立悬停框。颜色沿每条棱连续渐变，共用顶点的棱线颜色一致，并随时间缓慢流动；开启“减少动态效果”后保留静态渐变。第一次打开界面就能悬停，无需先点击模型。悬停不修改正式选区或草稿。
- **放置** 时，彩框预览点击后要新增的格子；越界、锁层、已有方块或条件不允许时显示红框。点击成功后蓝框选中新方块，鼠标不动时预览保留在刚放好的位置，移动鼠标后继续预览下一个目标。
- **触屏** 根据游戏的原生输入模式自动识别，轻触立即操作，任何时候只有一个选区框。常规点选的单格使用炫彩框；框选第一点后，炫彩单格固定在第一点，直到第二次轻触确定区域，再显示炫彩长方体。没有额外跟随鼠标的悬停框。Windows 开发客户端关闭界面后按 **F11** 切换触屏模式，重新打开后自动识别；F12 不用于切换触屏。
- **自动触屏适配**：跟随游戏原生输入模式，手机自动启用触摸操作，PC 原生模拟触屏也能识别；不再提供手动触屏开关。放置、单格擦除、换材质均为轻触一次直接执行，无需额外确认；拖动只旋转。浏览、选取、吸管与框选同样支持触屏，松手保留正式选择。手机读取 INPUT_MODE 设置；Windows 根据 F11 的 IsTouchWithMouse 开关识别，进入和退出模拟均立即生效，不等待缓存的 INPUT_MODE 更新。模组不绑定切换按键。
- **图层 → 场景亮度** 调整预览的明暗，不重新生成模型。三维预览使用固定光照，不随世界时间变暗；这个控件调整整个三维场景，框线和工具文字保持清楚。
- 输入框继续使用原生字体和整数 GUI 字形倍率。正在输入时仅该框变为中性深灰和浅色文字，使原生白光标清楚显示；取消焦点后恢复浅底深字。超长混排文本滚动到末尾仍有原生光标裁剪限制，详见 `INPUT_FONT_BATCHING.md`。
- **擦除** 的右栏提供 **单格 / 选区**。当前选中多格时，进入擦除自动选择“选区”，点击模型会保留原范围，点击右栏底部 **擦除选区** 一次删除范围内符合条件的方块。锁层和材质过滤继续生效，整次操作只需一次撤销，大范围可取消。选择“单格”后恢复逐块点击擦除，框线标记擦除后留下的空气格。
- 所有模式下拖动都用于旋转，超过移动阈值后不会同时编辑。松开鼠标后停止跟踪，保留短暂旋转惯性；拖出视口或切换页面会取消拖拽。放置模式点击空白处时，落点位于当前 Y 层；正视时射线与图层平行，可以切到俯视操作。
- 形状、纹理、修整使用当前正式选区；直接编辑更新选区到操作格，共用方块条件、图层锁与撤销历史。右侧 **全选** 恢复完整范围，坐标修改立即生效。框选第一点立即替换旧选区为一个格子，第二点扩展成长方体；第三点即为下一次框选的新起点。未确认终点时不能执行批量工具，切换模式取消未完成的框选并保留当前单格；空白处可以在当前 Y 层框选。
- **全部 / 方块 / 空气 / 材质** 过滤本次操作的目标位置；**方块** 表示已有的非空气方块，不表示生物实体。**材质** 使用单独的 **匹配材质**，与替换工具的 **替换来源** 相互独立。直接放置可跨出旧选区，仍受文档边界、图层可见性、图层锁和方块条件约束。
- **框选** 统一从视图下方进入；右侧集中提供 **全选 / 坐标设置** 与边界调整。下方 X、Y、Z 的 **下界 / 上界** 各有 − / + 按钮，每次移动一个方块，允许把空气位置纳入选区；自动限制在文档内，并防止上下界交错。它们与坐标输入和三维框选操作同一份选区。
- **网格** 位于当前 **工作层 Y** 的底面，每格都绘制边界线；64×64 平面具有每轴 65 条边界线，不抽样。使用底部 Y 的 − / + 明确调整高度，点击选取不会移动它。网格不改变选区或方块；非长方体选择的唯一蓝框显示其包围盒。
- 右侧只展示当前操作使用的参数：例如空心形状显示厚度、移动显示步长、随机混合显示比例和种子。横滑条留有端点空间，数值会按整数吸附；竖滚动条按内容长度显示，可点击轨道或拖动，也支持原生滚轮滚动。切换工具后参数面板回到顶部。
- 底部 Y 控件切换当前层；图层面板每页 16 层，支持翻页、锁定、隐藏和隔离。锁定保护编辑，隐藏只改变预览。
- 历史记录支持撤销/重做。状态栏显示当前方块、选区和材质数量。
- 工具箱支持中文名称、说明及英文工具 ID 搜索。
- **方块目录**：点击右侧常用方块列表末尾、与方块格同样大小的 **+**。目录按建筑石材、木材、彩色方块、自然、装饰照明、功能和模组方块分类；下方搜索框可直接输入中文方块名，也支持标识符。点击方块后选择 **添加并使用**。目录从当前游戏读取本地化名称，分页显示，不一次创建全部物品控件；内部无名称的方块状态不展示。
- **常用方块整理**：点击 **整理**，选中一个格子，再用 **前移 / 后移 / 移除** 调整。移除只删除快捷入口，不修改建筑或当前使用的材质。常用列表与炫彩速度保存在独立的本机设置中。
- **粘贴**：复制或剪切后进入 **粘贴方块 / 无空气粘贴**，场景显示剪贴板完整尺寸的炫彩包围框。PC 鼠标移动可预览位置，点击模型或当前工作网格固定起点；触屏轻触定位。右侧的 X/Y/Z 步进控件分别调整左右、高低、前后位置，**坐标输入** 可展开精确坐标，最后点击 **确认粘贴**。不需要框选同样大小的目标选区；**重新定位** 恢复鼠标预览。越界显示红框并拒绝整次操作；图层锁和方块修改条件仍生效，整次粘贴一次撤销，大范围沿用进度与取消机制。
- **炫彩流动速度** 位于右侧 **图层**，默认 **3 倍**（约 2 秒一轮），可调整为 **0.25–6 倍**。切换速度保持当前颜色相位，不重建模型；开启“减少动态效果”后保留静态渐变。
- 静态标签和动态名称使用现有 Noto Sans SC 字体的完整图集，包含 30,890 个字形，覆盖基本汉字、扩展 A、字体支持的其他文字和符号。“币”等名称中的字不再需要逐个补图，未被此字体收录的字符仍有原生字体回退。换行避免将句号等闭合标点孤立到下一行；输入框仍由原生控件绘制。
- 输入框保留原生字体，按游戏 GUI 倍率调整字号；当前常见窗口下使用 3 倍物理放大，比上一版的 2 倍大 50%，同时保留整数像素缩放。输入文字没有换成黑体，也没有新增文字图片。
- 建筑库的新建区域分别提供 **X · 宽度、Y · 高度、Z · 长度** 整数滑条，每轴两侧的加减按钮可精调一格。尺寸直接由控件生成，不经过原生文本输入和文字过滤；点击 **新建空白** 后显示实际尺寸并确认替换草稿。载入和世界捕获采用同一尺寸上限，旧的超限配置不自动截断。
- 拖住侧栏滚动条后，鼠标可以离开窄条继续上下拖动；在条外松手也会立即结束拖动。
- 按钮有弹性反馈，操作按钮带点击粒子，滑块有回弹，分段选项有移动背景，页面有平移淡入；入门指南提供减少动态效果开关。

## 预览构建与恢复

大建筑按 16×16×16 精确分块生成和显示，仍可看到整栋建筑，不降采样。首次构建时，进度显示为视口左上方的紧凑圆角卡片；可暂停并重试，失败时保留草稿和已生成的预览。切到其他页面不会因等不到原生显示确认而一直构建。放大后，屏幕外分块暂不提交相机变化，移回视口会恢复。无任务时停止统计预览进度，隐藏页面暂停滚动条同步；旋转时复用原生模型控件和同一帧的相机投影参数。

## 剪贴板分享与导入

在 **建筑库** 点击 **分享当前草稿**，或已保存配置卡片的 **分享**，等待准备完成后点击 **复制完整编码**，即可粘贴到聊天工具。导出已保存配置时使用该配置的完整存储数据。

接收方先复制分享码，再进入 **建筑库 → 导入分享码 → 从剪贴板读取**。校验成功后显示名称、尺寸和方块数，点击 **确认加入建筑库** 保存为一个新的本地配置；不会覆盖正在编辑的草稿，也不会直接放置世界方块。需要编辑时再从建筑库载入。

分享码超过 256 字符时提供分段复制，默认每段约 **512 字符**，可改为 **256 / 512 / 1024**；每段另有约 30–40 字符的序号与校验头。接收方逐段复制并点击读取，支持乱序和重复段，收齐才允许保存。接收界面显示缺失段号、绿色的已接收编号和浅灰的待接收编号，每页 24 段，可翻页或点击 **定位缺失**。同一轮发送使用同一种分段长度，混入不同建筑或段数不一致会提示清空。旧版 12,000 字符分段仍可接收。聊天软件的容量与手机剪贴板策略由实际平台决定。

格式为带版本与校验的 MP2；分段为 MPS2。限制完整文本为 8 MiB、解压数据为 16 MiB，尺寸上限仍为 64×128×64。损坏、未知版本、越界或不完整的数据会被拒绝。编码与解码有进度，关闭弹窗会取消尚未完成的任务。

分享内容包括名称、尺寸、方块标识与附加值，不包含箱子物品、告示牌内容、生物或结构 NBT。使用其他模组的方块时，接收方也需要对应模组；本地导入保留这些标识，之后写入世界仍由服务器验证材质和权限。

## 建筑数据保存在哪里

编辑中的草稿、选区和撤销历史保存在客户端内存。点击保存后，建筑库通过 `ConfigClient.SetConfigData(..., True)` 写入当前客户端的本地全局配置，因此在这台设备上切换世界仍能读取；它不是服务器建筑库，也没有云同步。名称、尺寸、方块数和页数保存在小索引中，方块按 16³ 材质索引分块编码并分页保存，避免每次读写一份巨大列表。

多人联机时，各设备的本地建筑库互相独立，其他玩家不会自动收到你的草稿、配置、投影或炫彩框。分享需要主动发送分享码。当前存储键没有再按游戏账号分隔，共用同一个客户端配置目录的账号不保证拥有独立建筑库。

读取世界选区、检查进度和应用到世界才会与服务器通信。“应用到世界”把建筑数据发给服务器，由服务器检查发送者和建造权限，再写入真实世界；这些真实方块会被其他玩家看到。退出游戏前请主动保存草稿。

## 投影和世界写入

投影是本地客户端的透明几何体，不修改真实方块，也不消耗材料。修改投影原点、图层或透明度后，点击更新。已有投影时，切换 **仅显示缺失方块** 会立即刷新：隐藏材质和状态均匹配的已完成方块，保留缺失和材质不符的位置；旧版木板、羊毛、原木等标识会先转换为当前版本对应的方块。搭建后点击 **更新投影** 重新检查，不会每帧扫描世界。建造进度通过服务端重新检查，区分已完成、缺失和材质不符。

大范围投影随玩家移动加载附近的精确 16³ 分块，同时保留最近的最多 32 个分块。远处方块仍保存在配置里，走近后显示。编辑器总览和世界投影都使用真实方块坐标与材质。

投影设置分为 **显示 / 辅助 / 写入**：显示包含原点、不透明度、炫彩范围框及炫彩流动速度；辅助包含缺失过滤、建造进度及材料清单；写入包含同步空气和应用到世界。炫彩速度与图层页共享，调整后立即生效，不重新生成投影。

投影及炫彩范围框均由本地客户端创建，其他玩家不会收到这些实体。**应用到世界**会产生真实方块，同一世界的其他玩家可以看见。

同时具有创造模式、操作员、建造和破坏权限的玩家可将草稿应用到世界。默认只放置非空气方块；开启 **同步空气** 后，会同步整个长方体并清除草稿中空气对应的位置，提交前再次确认。客户端只发送包含尺寸、材质表和压缩分块的有序数据包；服务端使用引擎提供的身份，在接收前、传输中和每个写入批次检查权限、维度，并检查距离、体积、加载状态及受保护的方块实体。完整接收并校验后，才由服务端调用方块接口。

**世界写入完成后无法撤销**，提交前请确认原点与范围；原“撤销世界写入”按钮及服务端操作已移除。写入过程中取消或失败仍会尝试恢复本次修改；如果区块卸载或世界状态变化使恢复不完整，会明确提示检查目标范围。工作台中的草稿撤销/重做不受影响。

缺失过滤后即使所有方块都已完成，投影仍保留整份配置的范围及外框开关；关闭过滤可以重新显示完整投影。尚未加载的世界位置不视作已完成，靠近目标并更新后重新检查。投影与外框仍只在本机显示。

## 当前范围与边界

- X/Z 各 1–64 格，Y 为 1–128 格，最多 **524,288 格**；本机建筑库最多 32 个配置。将新建区域的三条滑条拖至最右端即可创建 64×128×64 草稿；原有超限配置保留在库中，载入时明确拒绝，不截断或删除。
- 大范围工具按时间片运行，视口进度条分别显示 **正在修改方块** 和 **正在更新预览**。编辑阶段可 **取消编辑**，完成前草稿保持原状；原生预览生成阶段显示完成进度，不能撤销已提交给引擎的生成调用。普通单格连点只更新涉及的分块，不弹出挡住点击的进度浮层。填充等均匀分块操作有快速路径，逐格形状、随机纹理、连通填充等耗时会随体积增长。
- 草稿历史最多 50 步，按约 64 MiB 估算预算淘汰旧记录，至少保留最近一次。大配置分批保存与载入，旧版小配置仍可使用。
- 世界读取、进度检查和写入通过分包和分批处理，可 **取消世界操作**；写入中取消会尝试回滚。世界操作须访问大量原生方块 API，耗时与草稿编辑不同。写入路径使用独立测试世界中的小范围真实方块验证，本轮没有进行最大范围的世界写入。
- 配置保存方块名称和附加值，不包含箱子物品、告示牌文字、实体、结构 NBT 等内容；实际写入保护既有方块实体。
- 尚未实现各种方向性方块的完整状态变换，因此对楼梯、门等方块的旋转/镜像会明确拒绝。
- 水、火、传送门、部分自定义方块外观等受 SDK 方块几何体支持范围限制，可能不出现在三维模型中；方块数据仍保存在草稿里。
- 三维命中按方块格子的包围盒计算。楼梯、薄片等非完整立方体按所在格子选择；SDK 不显示的方块建议在逐层视图操作。当前支持逐次点击编辑，尚未提供按住鼠标连续涂抹。
- 编辑器三维模型采用固定光照，可在图层面板调整场景亮度。世界投影继续使用引擎世界光照。
- 世界写入使用与 SDK 读回及状态换算一致的传统 aux 参数，兼容常用旧版拆分材质，并保留原木朝向和树叶状态；关闭主动邻居更新以限制批量操作的连锁影响，游戏自身仍可能更新方块。复杂红石、液体及其他跨版本方块状态需要进一步兼容测试。
- 建造进度检查和投影刷新由玩家主动触发；本轮未添加自动补方块、材料消耗、跨客户端共享库、结构文件导入导出或选区物品。
- 剪贴板分享已接入建筑库，详见下方说明；Windows 游戏及 F11 模拟已验证，手机系统权限和聊天软件长度限制仍需各平台实测。
- 当前主要验证 PC 键鼠入口；触屏专用选区入口和完整移动端机型适配仍需后续工作。
