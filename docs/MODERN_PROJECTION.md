# 现代化投影 · 使用说明

这是面向网易我的世界基岩版 ModSDK 的建筑编辑工作台。当前版本为可运行的开发预览版；暂不注册选区物品。

## 开始使用

1. 进入开发世界会自动打开工作台，并显示可以编辑的庭院示例。
2. 关闭工作台后，按 **P** 重新打开。对准方块按 **F6** 标记起点，按 **F7** 标记终点；没有瞄准方块时使用脚下坐标。两点之间显示蓝色线框。
3. 再次打开工作台，点击 **读取选区** 并确认，将世界方块读取到本地草稿。
4. 左侧选工具，右侧的 **当前选区** 与三维 **框选** 使用同一份范围。先框选或展开 **坐标设置** 修改起终点，再设置主/副材质、方块条件和工具参数，点击 **执行**。所有草稿操作都限制在当前文档长方体内。
5. **建筑库**中可以修改名称、保存多个配置、载入、重命名、删除，或指定 X/Y/Z 尺寸新建空白草稿。
6. **投影**中设置世界原点、不透明度、图层和缺失过滤，点击 **更新 / 生成投影**。关闭工作台即可在世界中照着投影搭建。配置保存在本机全局库，切换世界仍可使用。

## 工作台

- 点击场景右上角 **展开视图** 进入专注编辑：收起工具箱、分类栏和页面页签，让场景使用大部分窗口。**还原视图** 返回完整工作台；相机角度、缩放、编辑模式和草稿都会保留。
- 专注编辑中仍可保存、撤销/重做、切换三维/逐层、直接编辑和调整 Y 图层；点击 **材质与属性** 可随时展开右侧参数、图层与历史面板，再次点击收起。场景标题下显示当前主材质。
- 三维视图使用原生方块几何体。拖动连续控制水平和俯仰角，松手有短暂惯性；左右转、正视、俯视、复位和缩放会平滑过渡。鼠标停在视图内时，滚轮可以缩放；最小为 25%，取消原来的 300% 放大上限。视图左下四个方向按钮平移画面，房屋按钮恢复角度、缩放与居中。平移后仍可准确点击编辑。
- 点击视图左下 **切面** 隐藏工作层上方的方块，再使用底部 **工作层 Y − / +** 上下移动切面，可从顶面查看并编辑建筑内部。它只改变可见范围，不删除方块；再次点击恢复。切面可与旋转、平移、放大、图层隐藏及精细视图配合。
- 大草稿总览保留真实方块坐标、材质与孔洞；移除了将每个 16³ 分块合成一个方块的旧预览。总览可直接操作，**精细** 按钮进入最多 32³ 的编辑范围，**总览** 返回完整建筑。参数中的 **精细视图中心 X, Y, Z** 可定位远处和地下，单格点击不会自动移动中心。
- 放置或删除方块时保留旧预览，在新的原生模型完成预热后切换；预览切换期间暂缓下一次编辑点击，旋转和缩放仍可操作。
- 三维视图下方提供 **浏览、选取、放置、涂装、擦除、吸管、框选**。浏览点击显示坐标；选取选择单格；放置沿点击面的外侧添加方块；涂装更换命中方块材质；擦除删除命中方块；吸管读取主材质；框选依次点击两个角点。蓝色线框只显示当前选区；浏览、放置和吸管不会额外创建一个小框。
- 所有模式下拖动都用于旋转，超过移动阈值后不会同时编辑。放置模式点击空白处时，落点位于当前 Y 层；正视时射线与图层平行，可以切到俯视操作。
- 形状、纹理、修整和直接编辑共用选区、方块条件、图层锁与撤销历史。右侧 **全选** 恢复完整范围，坐标修改立即生效。框选第一点不会改动原选区，第二点确认后才更新；未确认时不能执行批量工具。空白处可以在当前 Y 层框选。
- **全部 / 方块 / 空气 / 材质** 只过滤选区中的位置；**方块** 表示已有的非空气方块，不表示生物实体。**材质** 使用单独的 **匹配材质**，与替换工具的 **替换来源** 相互独立。直接编辑默认限制在选区中，可明确切换为允许编辑整个建筑。
- 右侧 **三维框选 / 全选 / 坐标设置** 在同一行。下方 X、Y、Z 的 **下界 / 上界** 各有 − / + 按钮，每次移动一个方块，允许把空气位置纳入选区；自动限制在文档内，并防止上下界交错。它们与坐标输入和三维框选操作同一份选区。
- **网格** 位于当前 **工作层 Y** 的底面，和方块边界对齐，大范围自动疏化线条。使用底部 Y 的 − / + 明确调整高度，点击选取不再自动移动它。网格不改变选区或方块；非长方体选择的唯一蓝框显示其包围盒。
- 右侧只展示当前操作使用的参数：例如空心形状显示厚度、移动显示步长、随机混合显示比例和种子。横滑条留有端点空间，数值会按整数吸附；竖滚动条按内容长度显示，可点击轨道或拖动，也支持原生滚轮滚动。切换工具后参数面板回到顶部。
- 逐层视图每页显示 12×12 个精确可点击的格子，用 X−/X+、Z−/Z+ 翻页。支持绘制、擦除、吸管，以及两点框选。
- 底部 Y 控件切换当前层；图层面板每页 16 层，支持翻页、锁定、隐藏和隔离。锁定保护编辑，隐藏只改变预览。
- 历史记录支持撤销/重做。状态栏显示当前方块、选区和材质数量。
- 工具箱支持中文名称、说明及英文工具 ID 搜索。
- 默认使用高清 Noto Sans SC 离线文字资源，未知字符回退原生 smooth 字体。
- 输入框保留原生字体，按游戏 GUI 倍率调整字号；当前常见窗口下使用 3 倍物理放大，比上一版的 2 倍大 50%，同时保留整数像素缩放。输入文字没有换成黑体，也没有新增文字图片。
- 新建尺寸支持英文或中文逗号、全角数字、空格以及 `×`、`*`、`x` 分隔。例如 `３，８，３`、`3×8×3` 都会创建 3×8×3。格式不完整时禁用新建，超出 256×384×256 时明确报错并保留当前草稿。
- 按钮有弹性反馈，操作按钮带点击粒子，滑块有回弹，分段选项有移动背景，页面有平移淡入；入门指南提供减少动态效果开关。

## 投影和世界写入

投影是本地客户端的透明几何体，不修改真实方块，也不消耗材料。修改投影原点、图层、透明度或缺失过滤后，点击更新。建造进度通过服务端重新检查，区分已完成、缺失和材质不符。

大范围投影随玩家移动加载附近的精确 16³ 分块，同时保留最近的最多 32 个分块。远处方块仍保存在配置里，走近后显示。编辑器总览和世界投影都使用真实方块坐标与材质。

创造模式可将草稿应用到世界。默认只放置实体方块；开启 **同步空气** 后，会同步整个长方体并清除草稿中空气对应的位置，提交前再次确认。服务端使用引擎提供的客户端身份，检查游戏模式、维度、距离、体积、加载状态及受保护的方块实体，并按批次执行。

**撤销世界写入**只撤销最近一次已完成的世界操作，跳过已被其他玩家改动的方块。写入失败时尝试回滚；如果区块卸载使恢复失败，会保留剩余恢复记录并明确提示。测试世界的 27 格写入/撤销已通过实际游戏验证。

## 当前范围与边界

- X/Z 各 1–256 格，Y 为 1–384 格，最多 **25,165,824 格**；本机建筑库最多 32 个配置。最大高度写入主世界时，原点 Y 必须为 -64，其他维度遵守各自建造高度。
- 大范围工具按时间片运行，状态栏显示进度，右侧可 **取消编辑**；完成前草稿保持原状。填充等均匀分块操作有快速路径，逐格形状、随机纹理、连通填充等耗时会随体积增长。
- 草稿历史最多 50 步，按约 64 MiB 估算预算淘汰旧记录，至少保留最近一次。大配置分批保存与载入，旧版小配置仍可使用。
- 世界读取、进度检查和写入通过分包和分批处理，可 **取消世界操作**；写入中取消会尝试回滚。数千万格的世界操作仍须访问大量原生方块 API，耗时可能很长。当前已验证最大尺寸草稿编辑与保存；实际世界写入/撤销验证为 27 格，没有将 2516 万格写入世界做破坏性压力测试。
- 配置保存方块名称和附加值，不包含箱子物品、告示牌文字、实体、结构 NBT 等内容；实际写入保护既有方块实体。
- 尚未实现各种方向性方块的完整状态变换，因此对楼梯、门等方块的旋转/镜像会明确拒绝。
- 水、火、传送门、部分自定义方块外观等受 SDK 方块几何体支持范围限制，可能不出现在三维模型中；方块数据仍保存在草稿里。
- 三维命中按方块格子的包围盒计算。楼梯、薄片等非完整立方体按所在格子选择；SDK 不显示的方块建议在逐层视图操作。当前支持逐次点击编辑，尚未提供按住鼠标连续涂抹。
- 原生三维模型和世界投影会受到当前世界光照影响，夜间预览可能较暗；界面文字和操作面板保持清亮主题。
- 世界写入保留当前版本 aux 值，并关闭邻居更新以限制批量操作的连锁影响。复杂红石、液体及跨版本方块状态需要进一步兼容测试。
- 建造进度检查和投影刷新由玩家主动触发；本轮未添加自动补方块、材料消耗、跨客户端共享库、结构文件导入导出或选区物品。
- 当前主要验证 PC 键鼠入口；触屏专用选区入口和完整移动端机型适配仍需后续工作。
