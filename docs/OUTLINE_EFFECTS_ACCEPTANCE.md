# 金色测绘与投影范围框验收

2026-09-24。实现依据是用户已确认的 `survey_golden_wireframe_preview.html`，本轮没有修改 HTML。

## 最终行为

- 两点测绘固定使用金色框、晶体、星芒和拖尾，不向玩家暴露风格设置。
- 每个选点用约 1.2 秒入场动画进入常驻状态。改变第二点不会重新播放第一点；两点重合时共用一个标记。清除选区时释放线框和标记。
- 投影设置的“显示”页提供炫彩、金色、星空，默认炫彩。每种风格独立保存线框流速、粗细和辉光亮度；金色、星空另有环绕速度和碎晶密度。
- 金色默认线框流速提高至 1.8 倍，环绕速度保持 1 倍。颜色使用连续空间场，让棱的交接处颜色连续。
- 金色和星空碎晶采用八个三角面的立体几何，切面亮度随翻滚与观察方向变化。螺旋是运动轨迹，没有额外绘制螺旋装饰线。
- 晶体原始尺寸偏小。常规选区的晶体轮廓已放大约两倍，大选区另按尺寸增加晶体与星芒的尺度。靠近镜头时限制显示尺寸并淡出，防止晶面遮住整个画面。
- 运动由 GPU 计算，框体保留 3 个客户端实体，两个选点最多再增加 2 个。静止时不反复上传相同参数；调整参数不重建建筑模型。
- 特效无碰撞、无重力、无实体阴影，使用客户端实体，不由服务器生成或同步。

## 渲染边界修正

移除了按镜头到无限延伸的选区平面距离隐藏框线的逻辑，也不再把眼后顶点挪到无关屏幕位置。框线交给原生裁剪器裁剪，避免整框隐藏或拉伸三角形。保留远处细线的最小可辨认宽度，并限制近处光晕宽度。

晶体的近距离缩放和淡出按整颗晶体中心计算，同一晶体的八个面采用相同参数，避免各面分离。最终近距离多帧截图没有再出现巨大的遮屏晶面。

## 2026-09-24：点击面、线宽与透明背景短测

- 选点请求携带 `PickFacing` / `GetChosen` 的原生 `face`，经服务端验证范围后回送客户端。原生 down/up/north/south/west/east 转换到 shader 的六轴编号；重合两点使用后一次点击面，移动相机不改变已记录的面。
- 金色/星空主框直接复用炫彩框的 `geometry.modern_projection.outline` 和顶点变换，默认实体棱线宽 0.045 格。颜色仍分别使用流金和星云材质；不关闭深度测试，不把正常前景遮挡当作背景错误。
- 主框与可见晶体/星芒写入深度，防止后画的背景水和树叶覆盖它们。透明粒子片元在极低覆盖度时丢弃，避免空白 billboard 写入矩形遮挡。保留晶体半透明混合与近镜头缩放/淡出。
- 点击轨迹横向尺度约增大 50%，中心星芒峰值半径由 0.36 提高到 0.50 格；点选晶体尺寸增加约 20%。框体环绕速度和实体数不变，最小绕线距离略增。
- 提高晶体暗面、亮边和星点的可见度，从现有尘埃槽位中划出 24 个随晶体切面朝向出现的镜面星芒，不增加实体或粒子网格数量。
- 定向单测：`tests.test_survey_effects tests.test_server_stream tests.test_bridge` 共 57 项通过。运行时模块审计为 83 个 Python 文件、违规 0。
