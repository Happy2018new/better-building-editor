# 场景设置与界面间距

右侧“图层”页签改为“场景”，下分“外观”和“图层管理”。外观中按“建筑外观”和“线框动画”分组，分别收纳亮度、群系染色以及炫彩速度；图层管理只保留 Y 分页、层选择、锁定和显隐。两个分组保留已创建的控件，沿用现有滑动选中条和按钮动画。后台仍由 PreparationQueue 分批准备，切换时不卸载再创建滑条。

主面板与底部状态栏之间增加 10 个设计单位的间距，同时扣减内容区高度，适用于普通视图和展开视图。执行按钮按用户要求显示“执行 · 工具名”；此前删除其他文案中点号的规则不变。

群系目录和当前选项使用相同的一套专用轮廓图标：草丛、树群、白桦树干、云杉、芦苇、红树林根系、丛林树冠、仙人掌、金合欢和雪花。10 张 48×48 PNG 合计 13,435 字节，由 `tools.generate_assets.biome_icons()` 生成，并接入完整资源生成流程。两处群系选择器共用同一组件。

验证：

- 运行 `verify_scene_settings_layout.py`，检查 PC 与 F11 原生触屏下的分组切换、10 个不同图标、执行按钮文案，以及普通/展开视图的实际底部间距。
- 检查 1920×1099 与 1200×900 客户区的实际截图；新图标在新启动的客户端中加载正常。
- 通过后台回归确认分组往返后 Slider 节点身份保持不变。
- 修改的 3 个业务 Python 文件通过游戏内 Python 2 编译检查；生成脚本通过宿主编译检查。
- 游戏错误日志为空，未发现原生断言窗口；`git diff --check` 通过。

F11 是 Windows 开发客户端的原生触屏模拟，本轮没有使用手机硬件。
