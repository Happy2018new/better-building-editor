## 阶段 32：批量性能、缓存历史与内部观察

- 最大 64×128×64、厚度 1 空心长方体由约 170.73 秒降到 8.33 秒（均含预览、调试查询和等待）。编辑自身墙钟约 2.00 秒、CPU 0.529 秒，预览约 5.03 秒。采用位集合薄板构造，只访问 39,944 个表面候选；保留掩码、锁层、原子发布与取消。墙、框架、底板也走该快速路径。
- Tracy 定位到进度更新反复触发根布局；进度改为固定控件布局、命令式更新文字/填色/可见性。编辑与预览使用渲染帧预算，UI 卸载时回退到计时器。缓存比较当前块、六邻块和材质映射，复用写时复制快照；空块不提交原生模型。该空心结构撤销/重做约 1.59/2.34 秒，无新增表面提取或几何构建。详细采样、热点和限制见 [EDITOR_PERFORMANCE_32.md](EDITOR_PERFORMANCE_32.md)。
- 前后移动使用独立的平滑视线深度，缩放保持不变。原生 PaperDoll 正交预览通过模型层级传递局部近裁剪参数，由着色器裁去眼前遮挡；射线起点和框线使用同一平面，不重新提交模型。引擎 3.9 实测矩阵关系、1/4 格精度及其他平台验证限制在性能文档中说明。预览最低顶点亮度避免封闭空间全黑，亮度控件保留。
- 恢复完整复位动画，清零推进、平移、旋转中心、惯性、拖动和延迟缩放；载入/新建保持立即复位。完成框选后鼠标悬停不再覆盖正式区域，下一次第一点立即开始新框，始终复用同一组 12 条边。
- 连续导航回归额外发现空白/有模型切换改变了无 key 的覆盖控件索引，导航边界引用被清空，屏幕级画布兜底误收按钮点击。覆盖层改为稳定 key；画布按下同时检查导航边界。
- 没有把 `CombineBlockPaletteToGeometry` 移入 `threading`：该原生接口没有线程安全保证，资料要求游戏 API 在主线程调用；Python 2.7 GIL 也不保证 CPU 计算并行。本轮消除无效工作并限制每帧原生提交。
- 137 项单元测试通过；最大尺寸原生连续放置 40/40 成功，约 4.175 秒，末步可独立撤销；批量进度/取消/全区清空历史 5 项通过，四比例大文档布局/裁剪/拾取/展开还原 60 项通过，内部编辑、选区描边和动画复位 12 项通过。MCDK 29 个业务文件解析全部通过，保留既有复杂度建议。
- 最大模型的 60–80ms 原生短按压力测试仍会丢失部分导航点击，保留 `probe_depth_buttons.py` 作为未通过的严格复现工具；不将其计入成功结果。层级刷新抑制、导航重路由和推进帧预算实验均未达到稳定目标，后者还拖慢长距离移动，已撤回。原生 `SetLayer` 仍是推进热点；10 秒压力记录 44.7 FPS 包含未执行的点击，不代表完整有效导航性能。相同最大结构的四页面切换前后均约 90 FPS，没有声称该场景进一步加速。
- 最终重启加载交付代码，内部观察/动画/选区 12 项和六模式悬停/触控回调 16 项再次通过，关键截图已打开。`editor_final_32.log` 的 AppReady 之后无 traceback、ERROR 或控件解析错误，独立原生 Assert 检查为空。载回原有 #005「林间白盒 · 建筑练习」，核对 24×16×24、1358 方块、完整显示、默认镜头、零推进、网格开启、亮度 1 和原生键鼠模式；恢复 2560×1494 最大化窗口。没有保存/覆盖/删除建筑库配置或写入世界方块；未做 Android/iOS 硬件验证。

## 历史阶段 30：16³ 局部编辑与分块原生提交

- 按用户选择，大草稿默认进入当前 16×16×16 分块，100% 编辑、围绕局部中心旋转；提供 X/Y/Z 相邻块切换、选中本块、整栋总览以及从总览定位选中块。切块不隐式更改正式选区，批量工具仍使用唯一的文档选区。上限提升为 64×128×64。
- 原生调色板改为每块自身的局部尺寸和索引，单份最多 4096 格，总览最多 128 份。统一相机计算各块中心，射线和框线加回文档原点；不降采样。模型控件使用稳定槽位池，切块复用，退出总览隐藏其他槽位。跨控件透明遮挡按用户授权让位于性能，保留玻璃原材质，不能宣称总览跨块透明深度已修复。
- 每块保留两个原生模型和内容缓存；只重建编辑块及必要邻块，撤销匹配已有内容时直接复用。批量任务记录变更块，完整文档填充走均匀块快速路径。视口增加方块处理/分块生成两个阶段的进度条，发布前可取消编辑。
- 蓝框悬停扩展至全部三维点击模式，框选第二点显示范围预览，不改正式选区。触控放置、单格擦除、换材质先预览再确认；浏览/选取/框选抬手选择。候选与正式范围仍共用一套 12 条边。
- 130 项单元测试通过；新增八象限射线穿越顺序、返回总览复用提取结果、连续编辑不发布遮挡进度和宽薄草稿默认局部编辑的测试。任一轴超过 32 格即默认局部编辑，64×1×64 不依赖体积门槛。未改动文档时返回总览只重新检查此前局部显示的块，其他块复用对应版本和显示条件的表面缓存。MCDK 28 个业务文件全部解析通过，保留既有函数长度、参数数量与 `sys` 导入提示。没有更换字体、新增 UI 图片或修改输入框结构。
- 实机调试曾出现逻辑响应但截图停滞/全白；临时唤醒显示后恢复，确认不能将息屏时的旧像素用作通过证据。验证工具在进程存活期间请求保持显示，不改系统电源配置，并加入两角度真实模型像素检查。完整树响应较大时调试器重复复制剪贴板会显著拖慢游戏；读取树后发送小型 ping 清理响应，防止性能测量被诊断负载污染。
- 初版总览性能采样定位到逐个 `SetLayer` 的同步刷新；改用 SDK 的 `syncRefresh=False, forceUpdate=False`，同一帧最后一次操作才请求刷新。但该原生调用自身仍有明显开销，因此进一步改成观察方向符号决定的字典序：射线沿每轴穿越分块时单调变化，字典序满足所有实际重叠块的前后关系，不再因互不重叠块中心深度交叉而重排。只在跨象限或可见分块改变时更新已有可见控件，隐藏缓冲在显示时设置层级。中间未达标采样保留，不作为最终性能结果。

## 阶段 5：预览连续性、帧率和专注编辑

- 调试剪贴板保留上一次 dump_tree 回执时，旧代码每个逻辑 tick 都重新解析整棵 UI 树。现在先识别自身已缓存的回执，并缓存非请求内容；相同 seq 的未送达请求仍只补发回执，不重复编辑。
- `Scene` 独占原生模型提交，app-local `PaperDollPrimitive.managed` 禁止 reconciliation 再提交相同模型。滚轮直接驱动相机，停止滚动 180 ms 后才刷新工作台上的百分比；发布前同步实际角度，避免与紧接着的拖动竞争。
- 选中框和自绘滚动条记录上次应用的状态，未变化时不重复写入原生控件。SDK 没有文档化的方块 PaperDoll 独立相机变换接口，因此旋转继续使用官方 RenderBlockGeometryModel，不臆造 GetModelId/骨骼模型变换接口。
- `PreviewBuffer` 持有两个始终挂载的透明预览控件。新几何体在旧图像仍显示时提交、预热，然后隐藏旧控件；空文档、被后续更新替换、提交失败和撤销取消均有生命周期测试。空闲时不重新提交模型，通常只显示一个渲染器。
- 实测隐藏 PaperDoll 会推迟初始化，带不透明背景的第二表面会遮住旧画面；因此预热表面必须可见且透明。也不在切换时调用默认同步 SetLayer，避免额外的 UI 刷新。
- **SDK 限制**：RenderBlockGeometryModel 返回的是提交成功，没有方块几何体 GPU 就绪回调。当前采用至少 3 个渲染机会且不少于 75 ms 的预热窗口，已在庭院连续放置中验证；这不是对所有硬件/所有规模建筑都无闪帧的保证。预览尚未追上文档时暂停新的点击编辑，仍允许旋转/缩放。

- 对照 `c3d96fe` 及相邻提交，旧 PageMotion 的水平偏移为 12 设计像素、280 ms cubic-out；阶段 44 的工作台却用了整屏宽度。这次将 WorkspaceMotion 改为同样的短距离右侧进出，打开 280 ms、关闭 200 ms，保留背景及内容渐变。旧版没有单独的工作台退出容器，因此本轮是恢复旧版的移动幅度和节奏，并非机械回退整个实现。三种弹窗仍共用 18 像素上下运动。
