# Plant Native Observation R11

The destination-origin adapter is implemented and tested, with an empty
production profile registry. It does not expand the accepted snow or plant
scope. Production remains at 29 positive states / 232 height observations and
8 observed negative lower-half states. Seed-name false rows are not observed
negative states.

The original-texture calibration completed at four predeclared destinations in
public and right views. All eight full native PNGs were opened. The same-session
stone calibration passed at vertical FOV 66.6. Native cells, support and platform
blocks, player position, world time, biome, camera and workspace were restored;
source assets stayed stable during observation. These images diagnose native
placement, not arbitrary-position rendering acceptance.

The alpha-preserving marker changed only the isolated pack's
`textures/blocks/flower_rose.png`. Its alpha hash exactly matched the native
texture. The first cold-start created an assertion dialog that violated the
required noactivation window contract; the guarded launcher terminated its own
processes. Foreground stayed on another application. An original-texture startup
control then passed and produced an opened fresh background WGC frame.

A marker retry using the separately verified MCDK build passed startup but
subsequently returned no bound runtime response. Camera calibration failed before
installing its probe or modifying camera, projection or world fixtures. The
opened fresh compositor capture contained the old embedded game time 21:30:39
although captured at 21:35:45. It cannot establish live rendering progress. The
game then exited. No geometry cause can be assigned from these observations.

Both marker overrides were restored. All four owned game/MCDK process pairs were
confirmed dead. The original baseline, failed manifests, camera failure and
frozen-content capture remain available and hash-bound in
`tools/data/plant-position-native-evidence-r11-v2.json`. No opaque marker was
installed and no holdout images were acquired.
