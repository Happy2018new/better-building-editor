# 法杖、安全区与手机输入修正（2026-09-25）

本轮基于 `b8e0922`，保留上一轮已提交的金色/星光外框亮芯、较大的环绕粒子、白色网格移除、原版 HUD 按钮间距、PC 操作说明和 P 入口移除。

## 机审与界面

- `OrbitCamera` 在构造时初始化视图基底和投影缓存，解决报告中的成员定义顺序问题。`get_safe_area_size`、SafeArea 使用处和两处剪贴板回复缓存读取显式转换 tuple；仍保留原来的空值与重试语义。已验证语法和测试，尚未重新向网易提交机审，不能把本地检查当作平台审核通过。
- 工作台采用不透明的全屏背景，内部内容/对话框按原生 SafeArea 的宽高排版，并裁切在安全矩形内。安全区探针每 0.5 秒重新测量，支持未改变屏幕分辨率的安全区配置变化。
- `navigatorScreenBase` 使用 `button.menu_cancel`、`button.menu_inventory_cancel`、`button.menu_exit` 原生映射；安卓 `OnBackButtonReleaseClientEvent` 是补充入口。两路共用去重，先关闭顶层对话框，再退出工作台，且只处理真正的原生栈顶。
- 触控 `TouchEvent=6` 是移出控件，不能结束 pinch；`0/3/7` 分别作为松手、取消、画布退出处理。新增 `button.multi_touch` 的非吞噬观察入口，保留 TouchId 和屏幕坐标；只有起点命中预览的手指才会被捕获，缩放完成不会变成方块编辑。

## 冰晶生成与手持物

选点的 23 颗金色晶体各自从本身中心生长，错开短暂的生成时刻。生成时有蓝白霜光和晶尖亮点；保持各自中心，生长完成后连续转入原有旋转轨道。已经取消上一轮把 99 个大碎片向同一中心聚拢的动画。时长仍为 1.8 秒，复用原有端点实体，重复选点重播同一条生成时间线。

`modern_projection:terminal` / `modern_projection:survey_wand` 的 ID、合成配方和功能保持兼容，外观分别为星穹法杖和星霜法杖。二者使用原生 attachable、第一/第三人称握持动画、金属镶边、深色杖身、中央宝石、五颗悬浮环绕晶体和尾部宝石。星穹款增加星盘装饰，并采用紫蓝星云；星霜款为青蓝星空。

宝石材质使用独立 GLSL shader：由观察方向决定星空采样方向，近、中、远三层星点具有不同的视差/漂移速度，并叠加流动星云和晶面反射。没有把原版末地传送门材质原样套到任意网格上。自有程序化星空不需要复制原版图片。32×32 物品栏图标及模型由 `tools/generate_astral_staffs.py` 确定性生成；旧工具生成器也改为调用它，避免重新生成资产时还原旧图标。

## 玩家魔法特效

手持任意法杖时创建一个本地、无碰撞、无阴影的客户端光环实体，固定上限 648 个编码四边形。Python 只同步玩家位置和少量 uniform；各个粒子由 GPU 计算。换另一根法杖复用实体，收起、打开工作台、切换维度或卸载时清理，延迟初始化回调不会复活已销毁实体。减少动态效果设置会冻结光环的运动时钟。

| 效果 | 运动 |
| --- | --- |
| 立体冰晶 | 椭圆环绕、独立浮沉、自转 |
| 三层星轨光带 | 不同倾角、不同方向和速度的轨道进动 |
| 地面符文环 | 脚下水平反向巡行 |
| 明暗星芒 | 三维 Lissajous 轨迹及独立闪烁 |
| 星尘 | 双螺旋上升，肩部以上渐隐 |
| 薄冰花瓣 | 向外展开的弧形回环，飘动并溶解 |
