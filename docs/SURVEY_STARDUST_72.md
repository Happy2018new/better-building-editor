# 阶段 72：世界测绘交互与星空选区

## 操作

- PC 手持测绘器，右键实际方块依次确定两点，左键直接导入。导入会新建本地配置，已有草稿和建筑库条目不被覆盖。
- 原生触屏模式直接轻触实际方块。`GetEntityByCoordEvent` 缓存 `GetChosen()` 的屏幕命中，`TapBeforeClientEvent` 确认短按后才提交；不回退到准星射线。拖动视角不选点。
- 完成后再点击方块开始下一次选区。移除标记第一点、第二点和重选按钮；触屏仅在两点完整时出现导入按钮。
- 手持终端可以右键打开工作台，也可以使用深蓝卡片样式的屏幕按钮。
- 服务器继续通过引擎 `__id__` 鉴别请求者，验证手持物品、12 格距离、维度与选区尺寸。视觉效果不能绕过导入校验。

`GetChosen()` 官方说明仅保证第一人称准确；本轮不将第三人称点选或 F11 模拟等同于实体手机验证。

## 效果与开销

世界选区由三个本地客户端实体组成：星空框线、淡白半透明罩和星尘。均无碰撞、无重力、无阴影，不创建服务器实体或方块。更换维度和关闭系统会释放它们。

线框采用独立 GLSL 星云噪声与星点，内部流动快于外围粒子。星点使用二维表面分布，避免把整条横截面染白形成刻度。线宽不随选区尺寸放大。

星尘在漂浮、沿棱流动、螺旋三种运动之间交错平滑过渡；少量间歇流星沿棱经过。运动由 GPU 时间驱动，Python 不逐颗更新。颜色集中在银蓝与淡紫，采用普通透明混合，重叠不累加成白光。粒子光晕、线框纹理和白罩透明度独立控制。

固定网格最多 3,072 个粒子槽（12 棱 × 256），按边长启用；未启用槽退化为零面积。每次选点附加一组 320 槽的划过效果，寿命 1.8 秒，最多三组同时存在。相机移动仅更新三个常驻实体和最多三个短命实体的锚点，不重建网格。原生包围盒随镜头锚点移动，着色器补偿世界位置，避免大选区转视角时整体消失。

网格粒子索引编码限制在 256 以内，并使用坐标绝对值解码，兼容导入轴翻转和移动端半精度。十二条棱均有覆盖。
