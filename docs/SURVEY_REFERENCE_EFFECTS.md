# 星空测绘参考效果重构

本阶段依据用户提供的紫蓝晶体流星、四芒星、星轨参考图重做选区与点选效果。实机画面是对轮廓、色彩和运动构成的重建，不将游戏截图宣称为参考视频的逐像素复制。

## 渲染

- 点选采用三条连续带状拖尾、四芒主星、局部光晕、56 枚八面晶体和细星尘。晶体是八个三角面的实际几何，具有独立的转动和面明暗。
- 选区保留淡白无碰撞罩；框线收细，紫蓝星云纹理加快流动。外围使用缓慢运动的虚实星轨、零散星点及错开的晶体流星。
- `survey_stars.vertex` 根据源网格地址生成不同形状。连续拖尾的相邻段共享端点；晶体把每个源四边形的一条边收为顶点，组成三角面。使用 `TEXCOORD_0` 定义四角。
- 实体材质的独立 `PROJ` 在实测路径不可依赖，广告牌宽度从实际绑定的 `VIEWPROJ` 正交行恢复。模型骨骼反转 Y，因此正向向上的特效路径先转换模型 Y，保证点击地面时流星从方块上方划过。
- 三个常驻本地实体；同时最多三个 1.8 秒点选效果。常驻网格 3072 个原始四边形，单次点选 768 个。Python 不逐颗更新星点、拖尾或晶体，只维护实体锚点和短命效果年龄。
- 世界效果不创建服务器实体，不放置世界方块，没有碰撞、重力或阴影。服务器身份、维度、距离及导入校验保持原有路径。

## 操作和按钮

- PC 右键两点选取、左键导入；按住潜行后右键清除。
- 触屏点击实际方块选点，调用原生 `Swing()` 挥手；拖动视角不选点。
- 设置第一点后显示“清除”；两点完成后触屏同时显示“导入选区”和“清除”。清除同步释放服务端点/区域记录与客户端特效。
- HUD 文案居中，增加星轨动画。原生 JsonUI 采用水平序列图与 UV 动画，不声称按钮使用了自定义 GPU shader。序列图 24 帧、3840×48，在 4096 纹理宽度内，不逐帧调用 Python。
- 使用 `SetFullPosition` 更新相对锚点的横向偏移，修正原来的 `SetPosition` 把底部按钮移到屏幕外的问题。

## 验证和证据

2026-09-24，网易开发客户端 3.9.0.401155，独立实例 `717d5a385ba840f1804a839f85c5a9cd`。

- 290 项离线测试通过；运行包 Python 模块白名单没有违规；原生断言检查为空。
- `tools/verify_world_tools.py` 真实 PC/F11 点选、拖动不误选、潜行右键清除、首点清除、完成区域清除、两种导入与终端打开通过。测试临时替换建筑库持久化为内存，并恢复原有四份配置。
- `tools/verify_survey_cinematic.py` 拍摄日夜、单格、64×128×64 及内部视角。相机变化不重建常驻实体；服务器特效实体为零；连续 20 次点选仍最多三个短命效果，随后正常回收。
- 最大区域远景测试让测试玩家随脱离相机移动，以使该相机附近的原生实体区块被加载。仅移动脱离相机不等价于实际玩家走到该处。
- 实际视频按已绑定游戏 HWND 录制，不录制桌面，不生成中间帧。30 FPS 是录制设置，不代表移动设备性能指标。静态流星细节图固定年龄 0.5，仅用于造型检查。
- `.runtime/survey74_comet_motion.mp4`、`survey74_orbits_motion.mp4`、`survey74_touch_swing.mp4` 为实机录像；`survey74_evidence.json` 保存运行检查结果；PNG 保存原始截图。

未进行实体安卓手机与多个真实客户端联机验证。固定数量保证开销有界；大选区远景的细星尘自然会小于一个像素，主要依靠细框线辨认范围。
