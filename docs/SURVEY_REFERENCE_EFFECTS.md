# 星穹测绘选区效果

本阶段按用户的“星穹线框方盒”描述重做世界测绘效果。实际用途仍是准确显示 Minecraft 世界中的两点选区，因此选区边界保持原位；慢转、倾斜、呼吸和爆发用于外围能量与晶体。不会强行旋转选区、放大选区尺寸或用黑色背景盖住游戏世界。

## 视觉构成

- 十二条光棱采用相机朝向的连续带状几何，同一片元内叠加白青细芯、冰蓝光晕和淡紫雾光。近棱稍亮、稍粗，远棱压暗；远景按线芯而非外围光晕保留最低屏幕宽度，避免大选区线条缩到亚像素后断续。世界选区没有面罩，内部完全透明。
- 共享空间色场使青、蓝、紫、品红在相交处连续。原生时间驱动流光和呼吸，不由 Python 每帧修改材质颜色。
- 两道白色流光沿闭合棱路径运行；路径覆盖十二条棱，其中四条棱会重复经过。点亮过程按同一路径推进，约 1.2 秒完成。
- 八个角有小十字星芒。创建选区时从实际相机位置选择最近顶角，固定主星芒在该顶角，观察过程中不会突然跳到另一角。主星芒有细白核、长横光刺、较短竖光刺、粉紫柔光和少量弱光斑。
- 主星芒向视野左下方延伸 16 条连续细丝，沿束长从白粉、品红、紫罗兰过渡到青和透明。细丝缓慢扭动，选区外保留两道很淡的弧形星轨。
- 常驻晶体上限 240 枚，其中 192 枚形成锥形晶体流，48 枚沿选区外围运动。另有少量细星尘。远处碎片较大但更早变淡。
- 晶体是实际八面几何，薄片与较厚晶体混合。各自的自转、进动、章动、相位不同；出生时间、方位和半径独立，避免粒子挤成周期性绳索。
- 晶体材质实现基于法线/视线的菲涅尔边光、面反射闪光、冷暖透光、青/品红彩边、内部裂纹和快速高光扫动。背面压暗，避免所有边叠成明亮网架。
- 每次点选触发 1.8 秒的短时星芒划过，使用同样的 16 条细丝和 40 枚晶体；选区附带约 0.55 秒的亮度爆发。最多并存三个点选效果。

## 遮挡与坐标

- 普通光棱、晶体和光束保留对世界方块的深度测试；不会把整个特效强行画到墙前。
- 增加独立的淡定位线层，仅画细框线，可以透过世界方块，便于识别被建筑挡住的选区。该层没有白罩、晶体或大范围光晕。
- 原生骨骼不仅反转模型 Y，还会旋转 X/Z。相机方向和主星芒坐标现在通过实际骨骼基向量转换，修正光束朝错方向、主星芒落在远角等问题。
- `entity_static` 不保证绑定独立 `PROJ`，广告牌宽度继续从 `VIEWPROJ` 的相机基向量恢复。
- 最近角的选择会直接读取当前相机，避免上一次短时效果已经结束后，用旧相机位置选择新框的主星芒。

## 原生能力边界

这里是实时实体材质，没有绑定可采样的场景颜色缓冲。因此内部光线残影与色散使用解析近似，**不是真正扭曲背景图像的折射**。透明碎片也不是电影渲染器那样逐像素排序的多层透明；不承诺真实镜面反射、光线追踪或物理景深。

所有视觉结果应以实机截图/视频为准，不宣称参考视频的逐像素复制或“影院级”物理光照。

## 运行与资源

- 三个常驻客户端实体：`guide`、`wire`、`stars`。分别使用 576、576、3072 个编码源四边形；每个点选实体使用 768 个。
- Python 只管理相机锚点、进入/爆发计时及销毁。静止且进入/爆发完成后，不重复上传计时和视线 uniform；粒子位置、翻滚、颜色和高光由 GPU 运算。
- 原生注册延迟回调会重新应用当前锚点与计时，不会把完成的入场动画重置为不可见，也不能复活已清除实体。
- 没有服务器特效实体，不放置效果方块，没有碰撞、重力或阴影。旧白罩模型、实体定义与对应方盒着色器已删除。
- PC 右键选点、潜行右键清除、左键导入为新配置；触屏按实际点击的方块选点，原生挥手，HUD 导入/清除。按钮保持现有居中文案与原生 UV 序列动画。

## 验证

2026-09-24，网易开发客户端 3.9.0.401155，独立测试世界，最终冷启动实例 `cd3d171b69ba47aab353419907030808`。

- 294 项离线测试通过；82 个运行包 Python 文件的模块白名单检查无违规，原生断言窗口检查为空。
- 单元测试覆盖大框相机移动不重建、编码网格在移动端半精度/镜像下的地址正确性、客户端无碰撞资源、快速点选回收、静止时无重复计时上传、主星芒稳定、新选区读取当前相机和延迟注册不重置动画。
- `tools/verify_survey_cinematic.py` 拍摄普通尺寸、单格、64×128×64、内部视角及日夜画面，并检查实体复用、服务器无特效实体和短时效果回收。测试相机/玩家位置、时间和选区结束后恢复。
- `tools/verify_survey_occlusion.py` 在独立世界临时放置石墙，对比开启/清除选区后的墙面像素，验证淡定位线实际可见。每个测试方块均在 finally 中恢复。
- `tools/verify_world_tools.py` 验证真实 PC 与 F11 点选、拖动不误选、清除、导入及终端打开。地形贴近玩家时，偏心点击和准星可能恰好落在同一格；本阶段在临时平整平台上完成该项回归，随后还原所有测试方块。
- 导入测试把持久化临时替换成内存，结束恢复原有四份配置与草稿。
- `.runtime/survey75_*.png` 为实机原始截图，`survey75_*motion.mp4` 为按绑定游戏 HWND 拍摄的视频。录像帧率是录制参数，不作为移动设备性能指标。

尚未进行实体安卓手机或多个真实客户端联机画面验证。
