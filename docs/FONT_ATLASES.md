# 现行字体资源

输入框继续使用原生字体及整数倍率。静态标签和动态建筑名称使用同一 Noto Sans SC Medium 的完整字形图集，不通过扫描当前文案决定汉字覆盖。

- `font_atlas.py`：30,890 字形，50 张 `atlas_000..049.png`，34.10 MiB。包含此前缺少的“币”等字及字体本身支持的扩展汉字。
- `type_assets.py`：650 条静态短语，11 张 `phrases_000..010.png`，4.72 MiB。它是常用文案只需一个原生图像控件的快速路径；未知/过长短语仍使用完整字形图集。
- 每张图集最多 2048×2048；短语条目显式记录 UV 和 UVSize，切换贴图时不会继承上次裁剪。

阶段 54 删除了全部 1,918 张旧十六进制文件名散图，包括重复单字、迁移的短语和孤立图片（6,755,577 字节），加入 11 张短语图集（4,944,079 字节），净减少 1,811,498 字节，即 1.73 MiB。整个字体 PNG 目录从 1,968 张减少到 61 张。保留完整字形覆盖需要的 50 张页和 OFL 许可，没有为了节省体积缩小汉字范围。

493 条打包前后共同存在的短语逐像素比较：透明度通道和尺寸全部相同；更换的是存放方式，不是字形。扫描业务 Python、JSON、工具和测试后没有旧图片名引用；单元测试要求目录中的每张 PNG 都被当前映射引用，所有裁剪均位于页内。

生成命令：

```powershell
python -X utf8 tools/generate_phrase_atlas.py --font .tools/fonts/NotoSansSC.ttf
python -X utf8 tools/generate_font_atlas.py --font .tools/fonts/NotoSansSC.ttf
```

`generate_assets.py` 调用这两个生成器，不再重新生成旧散图。完整字形生成器按现有字形图集位置保留顺序，不依赖短语表的单字项。

阶段 54 同时移除导入弹窗“缺少第 … 段”的重复长句，保留接收计数、编号网格、分页和定位缺失。预览提示将进度与“取消”并排放置，取消后提示“已取消更新，可重试”；取消丢弃当前构建任务，重试重新构建，不宣称暂停后续传。

`verify_orbit_polish.py --background` 使用实例内回调、内存剪贴板替身和不切前台的 PrintWindow 截图，不发送桌面输入或调整窗口。后台调用和字形/状态检查已通过；部分后期 PrintWindow 返回空白，不能将这些图片当作进度卡片的视觉验收。真实窗口尺寸变更、原生剪贴板及最终前台点击需在桌面可用时运行不带 `--background` 的入口。
