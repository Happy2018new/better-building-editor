# Alpha Marker Single Control R11

This is a launch plan, not native evidence. No game was launched while preparing
it. It is limited to the existing predeclared calibration cell `(6,117,6)` and
public offset `(-2,.15,-2.5)`. The immutable independent marker plan remains
`cc3852cb22b99d676521e2d91bbf50d814e1464b736ff7ea7e6a11093aa67641`.
No opaque marker, holdout, Y repeat, new geometry fit or production profile is
part of this control.

The root agent must first publish a fixed-IPC build hash, a passed bound runtime
smoke, and the snow slot authorization. Keep the existing noactivation DLL and
background-only capture constraints. Do not start a game before these conditions
are met, or repeat a launch after missing runtime values without a new root
decision.

1. Offline, install one fresh `prepare_marked_native_plant.py` alpha snapshot in
   the isolated worktree. Verify the native alpha hash and candidate alpha hash
   are both `7060164de76ea6e3de651a42f4a6dfbdae27dc4d86daccbd5f7b1807fce1008c`.
   Keep the candidate and snapshot, and enter a host `finally` that restores the
   bitmap bytes even if startup fails. Never modify the installed vanilla pack.
2. Cold-load one owned game with a root-supervised startup deadline of 90 seconds.
   Verify game/MCDK process creation identities, owner/project, guarded HWND and
   initial `WS_EX_NOACTIVATE`, then require two fresh nonce-echo client and server
   runtime responses with advancing Windows Python process clocks. No fixture,
   projection or camera mutation is permitted before this gate. Runtime progress
   proves responsive Python execution; fresh WGC timestamps alone do not prove
   rendering progress.
3. Run the existing independent stone camera calibration once in this same
   session. Bound its host subprocess to 150 seconds. Missing direct values,
   invalid native capture or calibration failure ends the session. Preserve the
   failure and skip plant mutation.
4. Run `verify_marked_native_plant.py` with `--single-positive-control`,
   `--stage alpha_marker`, `--partition calibration`, the immutable plan, fresh
   snapshot, and the passed same-session camera report. Bound its host subprocess
   to 150 seconds. The observer uses 8-second MCP calls and 20-second polling
   deadlines, checks fresh client/server runtime responses before fixture
   mutation, and captures one shown/blank pair at the declared public view.
   Each owner-bound native WGC helper already has a 15-second subprocess timeout.
   The observer repeats its runtime gate after capture and rejects an empty
   shown-to-blank diagnostic mask.
5. Open both full native PNGs and the middle-half diagnostic mask. Require a
   visible asymmetric grayscale marker on the poppy and disappearance at the
   same camera pose when the client palette becomes air. Record the reviewed
   pixel evidence in a separate fresh receipt; `marker_pixels_verified=false`
   in the observation report cannot be promoted from file hashes, clip boxes,
   fresh compositor timestamps, an advancing Python clock or a nonempty generic
   difference mask. If the pixels freeze or the marker is absent, retain failure
   and end the session. Do not tune geometry or capture another cell.
6. Always run fixture/camera/workspace cleanup while the runtime responds, request
   normal stop only for the owned session, and verify both owned creation
   identities are dead. If runtime IPC or a host timeout prevents cleanup, stop
   only the bound owned processes and preserve explicit incomplete restoration;
   never report the isolated world as clean without receipts. After stopping,
   restore the isolated bitmap from its snapshot and verify the override is
   absent and the installed vanilla texture hash is unchanged. A restored
   original-texture positive control is required before any later acceptance
   observation; it needs a separate root slot.

Only the parent supervisor can enforce the whole startup/calibration/observer
wall timeout. On timeout, mark the attempt incomplete and terminate only its
helper, then stop only the bound owned session and restore the host bitmap.
Neither the observer nor native WGC claims that a blocking OS/GPU/IPC call is
bounded by a polling deadline.

The single-control CLI can also capture `--stage original` at this same one cell
and view during a separately authorized original-texture session. This does not
change the immutable baseline pack or acceptance thresholds. Both modes retain
`production_acceptance=false`.
