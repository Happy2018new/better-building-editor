# R28：干态红石线支撑候选与上坡严格拒绝

生产代码仍只包含干态 aux5 地面拉杆的冗余混凝土支撑修复。红石线扩展候选没有合入，混凝土邻格变色 OB-10 继续开放，新增人工关闭 **0**。本轮沿用原有严格像素门，没有为单像素差异降低标准。

候选只停止为干态红石线重复复制正下方混凝土格，保留红石线目标、其他邻格和逻辑文档两层；SHA256 为 `cd37869a6d9f1222e148e9fc7143fc51f98648e75cd31523eddaed02db76fa1a`。私有副本固定水纹以排除已知动画基线变化，非产品水改动。旧 R27 失败、解码修正与证据保持在 [上一轮记录](WIRE_CONTEXT_R27.md)。

## 离线与退出

私有业务对照覆盖 1,024 正例、1,288 反例及 2 份混合缓存文档；20 项账本解码控制通过。root 又在隔离候选上执行地面拉杆既有测试和拟议红石线测试，9 项通过，没有为未晋升候选修改生产期望。MCP 候选范围解析 1 文件，仅保留原有结构提示。

原生诊断对象与 Python 状态的恢复分开记录。普通 exact-owner stop 后，同原进程句柄测得 game 退出 **0xC0000409**、MCDK 退出 **0**，无原生堆栈，不推断指定组件根因。registry 随后确认停止；专属 watcher 在游戏退出后按精确创建身份回收，exit 0。没有强杀游戏或重启。
