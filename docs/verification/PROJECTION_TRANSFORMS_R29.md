# R29 投影页旋转／镜像与真实放置

2026-10-26 北京时间，本轮已在本地 `dev` 实现投影页的方向设置，并让生成、缺失过滤、建造进度和真实方块写入使用同一份变换目标。产品实现为 `25e83e31`，小型公开对照卡为 `bef84e5a`，来源审计和独立世界 smoke 工具为 `ad4a3331`。截至本文初次记录，原生显示和真实游戏写入仍待实测，新增用户人工关闭数为 **0**。后续结果在下方追加，不能把实现或 CPU 回归写成人工接受。

## 已实现的行为

- 投影页选择 Y 轴 0°／90°／180°／270°，以及 X／Y／Z 镜像；顺序为先旋转，再沿目标坐标轴镜像。页面显示最终范围，并提供恢复原始方向。
- 生成／更新时立即捕获原文档的写时复制快照，逐帧准备变换后的完整 `Document`。90°／270°交换 X／Z 范围，目标局部最小角仍为原点。编辑器文档、建筑库、名称和群系保持原值。
- 方块状态、前景／背景、受支持的 actor／NBT 及伙伴坐标继续复用 `cell.transform`／`cell.rebase`；世界适配器仅增加一次原点，原生写入旋转参数保持 0。不增加服务端第二套旋转规则，不补造缺失的半门或半床。
- 完整投影、缺失投影和占据跟踪读取同一变换文档及原点。上下镜像同时映射隐藏层和独显层，包含小蓝图和超过 4096 格的批量路径。
- 成功发布后才替换当前目标；更新失败保留原投影。设置或草稿已改变、但新投影尚未成功生成时，拒绝按新设置检查旧投影或写入世界。
- “应用到世界”的确认框列出原点、范围及变换；确认回调固定文档、原点、操作和同步空气设置。确认框打开后更改草稿或设置，不会改写已经确认的目标。
- 检查和写入以整个建筑为范围，包含编辑器切面隐藏的楼层，页面已说明这一点。同步空气继续遵循原有选择。

未知状态不能安全变换时拒绝生成，保留原投影并显示具体原因。准备取消／失败会清除首次请求状态，不会在随后切换“仅显示缺失”时意外重启；读取世界选区与材质解析不因无关投影设置改变而丢弃结果。
