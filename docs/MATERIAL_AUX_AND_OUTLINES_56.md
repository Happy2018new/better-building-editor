# 附加值、材质切换与视线裁剪

## 行为

- 已确定的选区不再被“前移／后移”的模型深度平面切断。PC 蓝框、触屏炫彩选区、框选第一角和待确认的范围、粘贴范围均保留完整边界；超出视口的部分仍裁剪。鼠标悬停框和工作网格继续遵循模型深度平面。
- 方块目录底部可设置附加值，支持输入、加一、减一、归零。空值、过滤后的星号、负数、小数、超出 0–32767 的值禁止添加；加减或归零可以恢复有效值。空气固定为 0，具体状态是否存在由该方块定义。
- 目录和常用方块格子右上角都有蓝色方形底、白色数字角标，包含 0。相同标识符、不同附加值是独立的快捷项；保存格式仍为原有 `(identifier, aux)`。
- 修改附加值后读取并缓存游戏提供的中文变体名。例如旧标识符 `minecraft:wool` 的附加值 15 显示“黑色羊毛”。无译名的自定义状态保留基础名及附加值。

## 材质切换性能

原路径每次 `set_editor` 都全局 `emit()`，导致工作台及隐藏页面更新。第一轮收窄通知后，采样又发现原生 `UpdateScreen` 仍占约 15 ms。最终将两种事件分开：`materials` 只更新当前材质，`palette` 更新快捷列表结构。选中底色通过 opacity 快速路径改变，名称复用已有字形，摘要图标直接更新已有 ItemRenderer。原生按钮保留，不重新挂载；框架本体无需改动。

同一游戏实例、同一 64×128×64、20,649 方块椭球，48 次以 90 ms 为最短间隔的材质选择。选择由游戏帧回调调用 Session，故以下是界面更新基准，不是手机硬件测试或端到端触控延迟保证。未启用 cProfile 的结果：

| 指标 | 修改前 | 最终实现 |
| --- | ---: | ---: |
| 整个工作台更新次数 | 48 | 0 |
| 方块模型重建次数 | 0 | 0 |
| 帧间隔 P95 | 120.37 ms | 15.33 ms |
| 最长帧间隔 | 261.41 ms | 19.44 ms |
| Python 帧处理 P95 | 107.57 ms | 2.80 ms |
| Python 帧处理最大值 | 248.89 ms | 5.39 ms |

记录：`.runtime/stage56_material_before.json`、`stage56_material_final.json`。中间版 profile 在 `stage56_material_profiled.json`。不同采样期间帧率基线有波动，不据此宣称固定 FPS。

## 验证与复现

- `python -X utf8 -m unittest discover -s tests`：231 项通过，覆盖附加值验证、四种材质通道、偏好存储、无文档修改、局部通知以及线框深度策略。
- `verify_material_aux.py`：PC 和 F11 原生触屏加减/添加真实点击，目录预览及中文变体名，输入过滤恢复，角标及常用列表。输入数值通过 Pyreact 输入接口设置；不能称为手机输入法硬件验收。
- `--palette-only` / `--touch-palette` 将正式 `MaterialPicker` 组件临时挂在独立测试卡片，PC/F11 各连续 12 次真实点击，核对完整选择顺序；不替换产品布局。工作台参数区的原生滚动定位本轮未成功，因此这项真实点击验证不代表滚动到底部的整条路径已验收。
- `verify_depth_outlines.py`：当前大椭球的选区在深度 0、50、90、0 中均保留 12 条原生边，位置和尺寸一致，无模型重建；触屏策略通过临时覆盖输入模式检测验证，结束时恢复。
- `verify_orbit_polish.py --final-only`：原始最大椭球逐格一致，预览完成、SDK 回调恢复，41 个模块通过嵌入式 Python 2 编译。

所有实机脚本经 `run_live_check.py` 绑定实例和桌面锁。附加值测试以临时内存偏好保存函数代替配置写入，结束后恢复草稿、材质列表、材质通道、相机与原输入模式。无世界写入或剪贴板操作。
