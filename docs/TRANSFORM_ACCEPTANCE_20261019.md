修正后的 schema 2 报告先使用现有 `Document.from_data` 验证与解码，再按坐标比较每格完整 `cell.encode` 内容；不会只比较 `Cell` 的前景元组视图。NBT 中 bytes／text、int／float／bool、list／tuple、列表顺序及显式 SDK 类型标签均保留。选区、端点、历史长度、修订和锁层继续严格比较。每阶段的 `encoded_equal` 单独说明原始文档是否相同；原始编码不同时，`document_encoding_differences` 保存未经重排的 actual／expected 文档与完整 JSON 路径差异。文档解码失败或真正内容不同仍会记录 `mismatches` 并停止，不能靠规范化掩盖。
