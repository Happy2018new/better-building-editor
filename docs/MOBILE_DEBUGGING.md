# 手机真机调试记录

本项目的 MCDK 连接器目前管理的是 Windows x64 网易客户端实例；它没有把桌面 MCP 地址直接暴露给安卓游戏的通用桥接。Windows 的 F11 只模拟触屏输入，不能证明安卓设备的多指事件、异形屏安全区或系统返回键。

网易开发资料提供的手机路径是 **开发者平台 → 手机版测试工具下载** 获取手机版开发自测包，再用开发工作台的 **联机大厅多人上线自测**。启动手机版自测包后，从联机大厅的“扫一扫”扫描开发工作台服务端日志按钮旁的二维码加入房间。这个流程会同时产生本地客户端和远程服务端日志，适合核对手机行为；普通本地测试的日志窗口只代表本地客户端。2026-09-25 已读取核对[网易官方《联机大厅调试与多人测试文档》](https://mc.163.com/dev/mcmanual/mc-dev/mcguide/26-联机大厅/20-联机大厅调试与多人测试文档.html)。这条流程只适用于能够进入这类联机自测房间的作品。

对本地单机模组，先通过自测包实际提供的模组导入/作品自测入口安装当前版本；电脑开世界本身不会自动把模组部署到手机。不要把 `127.0.0.1` 的 MCDK 地址填到手机：那是电脑本地回环地址，也没有经过项目的实例路由校验。

2026-09-25 已读取核对 [Android 官方 ADB 文档](https://developer.android.com/tools/adb)。安卓手机可以先按以下方式连接电脑采集日志：

- USB：安装 Android SDK Platform-Tools，在手机开发者选项打开 USB 调试，用数据线连接并在手机上允许这台电脑，运行 `adb devices -l`，确认设备状态为 `device`。
- Android 11 及以上无线方式：电脑、手机连接同一 Wi-Fi，手机打开“无线调试 → 使用配对码配对设备”，运行 `adb pair 手机IP:配对端口` 并输入手机上的配对码。配对端口与连接端口可能不同；若未自动连接，再用无线调试主页显示的地址运行 `adb connect 手机IP:连接端口`，最后执行 `adb devices -l`。
- 日志：复现前执行 `adb logcat -c`，完成一次复现后用 `adb logcat -d -v threadtime > phone-log.txt` 保存日志。也可以在开发自测包自身的日志界面查看 Python 输出；普通发行包不保证把 Python 输出转到 logcat。

这条 ADB 路径只用于连接设备、采集日志和截图，不等于网易客户端已经提供远程 Python 执行或 MCDK 控制。后续有具体手机版本后，再确认它实际开放的调试入口；不需要 root，也不需要开放电脑 MCDK 端口。

这轮代码已把有限触控诊断留在 UI 宿主上：设置 `_projection_trace_touch = True` 后，`_projection_touch_trace` 只保留最近 48 个 `TouchEvent`、`TouchId` 和坐标。重点检查以下顺序：第一根手指 `1/4`，第二根手指 `1/4`，两根手指距离变化，分别 `0` 释放，最后 `onPinch` 为 `end`；`TouchEvent=6` 只是移出控件，`7` 才是画布离开。手机上还应确认切换异形屏方向后安全区仍覆盖内容，系统返回键先关闭顶层弹窗，再关闭工作台。

建议的真机回归顺序：

1. 手持测绘器打开工作台，在预览中央双指向外/向内移动，检查连续缩放且不会生成选点；将第二指移出预览后继续移动，再松手。
2. 打开材料目录或重命名弹窗，按安卓系统返回，确认只关闭当前顶层界面；再次返回才关闭工作台。
3. 旋转或使用带刘海/圆角的设备，确认内容和按钮都在安全区内，安全区外由全屏背景遮住游戏画面。
4. 手持两种法杖离开工作台，确认身边出现冰晶、星芒、轨道带、符文、星尘和冰片六类效果；切换物品或切维度后特效应销毁。

提交手机日志时请同时记录设备型号、系统版本、客户端版本、屏幕方向和复现步骤。桌面 MCDK 截图、F11 模拟和 Python 单元测试不能替代这组真机证据。
