# 材料清单复用方块目录的中文名

“所需材料”和历史页“材料清单”原来只读取名称缓存，未打开方块目录时会显示 `grass`、`planks` 等旧 ID。现在两处均调用物品选择界面的 `Session.describe_material`，按需查询游戏名称并复用共享缓存。

名称查询先通过当前方块表将旧 ID 和附加值解析为对应种类。例如 `planks:1` 对应云杉木板，`stained_glass:9` 对应青色染色玻璃。该转换只用于查询名称，不改写草稿、附加值、材料计数或存档。查不到的名称不再永久缓存为英文回退值，后续目录加载可补齐；两份清单订阅目录完成通知，刷新已有文字。

验证：

- 248 项单元测试通过，包括旧方块变体名称、共享缓存、查询失败后重试和建筑数据保持不变。
- 独立 MCDK 实例在未打开方块目录时，两份材料清单均显示中文。
- 通过实际目录加载后，再次检查两份清单及截图，名称和数量为：石英块 615、草方块 400、云杉木板 155、橡树树叶 54、青色染色玻璃 44、玻璃 39。
- 未发现原生断言弹窗。实机脚本调用 UI 回调并检查控件文字和游戏截图，没有写入世界方块或用户配置。

复现工具：`tools/verify_material_names.py`，通过 `tools/run_live_check.py` 绑定新启动、尚未打开目录的测试实例执行。证据保存在 `.runtime/material_names_checks.json` 和同名前缀截图中。
