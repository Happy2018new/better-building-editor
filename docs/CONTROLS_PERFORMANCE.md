## 外观与动画验证

- 原生模型启用 scissor 时，分数裁剪边界会在右侧/底侧留下不受弹窗遮罩影响的白线。保留 scissor，只把独立模型裁剪框收缩到整数 UI 边界，并反向平移模型容器以维持原点；最大 300% 缩放仍正确裁剪。普通/专注视图及四种比例共 52 项适配、命中、裁剪边界检查通过。
- 输入框关闭原版背景，用固定圆角背景包裹原生编辑控件；使用原生已有内边距，避免窄附加值框重复缩进后裁掉数字。悬停/按下改为给同一圆角面着色，消除拉伸的椭圆。
- 分段背景在父页面提交完成后启动 300 ms 位移，避免页面重排吃掉动画前半程。原生坐标采样为 `2.53 → 6.68 → 27.74 → 70.41 → 71.69`；快速反向切换后精确归位。
- 确认弹窗保留退出阶段，遮罩渐变、卡片缩放和平移同时播放；按钮在退出时失效，Modal 继续拦截底层点击。进入、退出、反向切换等 6 项检查见 `tools/verify_motion.py`。
- `verify_motion.py` 沿用 seq 调试协议，缩短外部轮询间隔；标准 CLI 单次等待约 150 ms，不适合观察 300 ms 动画的完整过程。
- 原生鼠标 6 项检查通过。测试发现外部音乐浮窗可能遮住滑条，即使前台窗口仍为 Minecraft；性能脚本新增实际命中窗口校验，避免把点击其他浮窗当成有效 UI 负载。
- 专注编辑的 8 项回归通过，放大后视口面积保持 2.31 倍。最新连续放置采样约 3 秒 / 94 张画面，四次真实放置成功，未发现模型消失样本（基准覆盖 6113 像素，最低 6111）；这不等同于采集每个输出帧或覆盖任意规模建筑。
- 原有 16 项 UI 流程回归通过，包含输入配置名、保存/载入/删除、确认框、图层、投影创建与移除。业务脚本 MCDK 检查 13 个文件全部解析成功，保留函数长度、参数数量和既有 sys 导入的静态建议。

悬停状态由各按钮独立持有，不更新工作台会话、不重排页面。120 ms 的透明度过渡只作用于局部背景，结束后停止动画帧订阅。选中背景继续沿原生 transform 路径移动；圆角半透明接缝通过对齐内部切点处理，未增加新的布局节点。
