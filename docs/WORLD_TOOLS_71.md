# 阶段 71：可合成的世界测绘器与投影终端

> 本文的验证记录保留阶段 71 当时的结果。最新交互与星空效果见 [阶段 72](SURVEY_STARDUST_72.md)。

## 使用方式

两件物品位于装备类别，各自最多堆叠 1 件，使用不消耗、不掉耐久。资源使用独立的 `modern_projection` 标识符，以及确定性生成的 32×32 像素贴图。

| 物品 | 标识符 | 用法 |
| --- | --- | --- |
| 投影测绘器 | `modern_projection:survey_wand` | PC 右键两个方块后左键导入；触屏轻触两个方块后点击“导入选区”。导入自动在建筑库新建配置。 |
| 投影终端 | `modern_projection:terminal` | 右键使用、触屏短按，或点击手持时出现的“打开投影工作台”。P 快捷入口继续可用。 |

测绘器的世界框仅在本人客户端绘制，两点都按方块坐标包含在选区内，最多 64×128×64 格。不再提供标记角点和重选按钮；触屏完成两点后显示“导入选区”，PC 使用左键导入。完成后再次在世界选点会开始新的选区。切换维度会清除旧坐标。持有工具时禁止破坏方块；拖动视角不触发短按选点。

进入世界不自动打开编辑器。世界选区导入完成后，玩家在建筑库选择“载入”才会将其作为编辑草稿。此时沿用原有载入确认。

## 数据与权限

- 客户端只发送选点、重选、读取请求。服务器使用引擎提供的 `__id__` 识别发送者，验证实际手持物品、选点距离、维度与范围；导入范围必须与服务器记录的选区完全一致。
- 世界读取与传输沿用分帧和分包实现，显示百分比；长时间无响应会结束等待。取消或换维度会终止读取。此功能不写入世界，生存模式可以使用；实际世界写入仍由原有服务端权限校验控制。
- 导入按“世界选区 X,Y,Z”新建本机配置，重名自动增加序号。当前草稿、撤销记录、已有配置保持完整。
- 建筑库满 32 份或存储失败时，待保存的导入保留在本次会话内；到建筑库清理空间后可点“重试导入选区”。仍有待保存结果时拒绝另一份导入。保存和载入不能中断正在进行的存取任务。
- 仅保存方块标识符和附加值，不保存箱子物品、生物、告示牌文字或命令方块等方块实体数据。世界选区框和建筑投影均只在本人客户端显示。存档沿用本机建筑库，不是服务器共享库。

2026-09-23，网易开发客户端 3.9.0.401155；独立测试世界，导入测试用内存代替建筑库存储，用户原有 3 份配置未修改。

- 完整离线测试 **285 项通过**，涵盖物品/配方/贴图注册引用、选区越界、服务端身份/距离检查、配置重名、满库、保存失败重试、I/O 并发保护；包含 behavior_pack Python 模块白名单检查。
- 最终冷启动实例 `b46094440cf3423099dac36d16437818`：物品名称、提示、最大堆叠和原生配方查询均正确。
- PC 真实右键打开终端、世界两点选取通过。F11 原生触屏模拟下，HUD 导入、重选、准星标记、终端打开均通过；按钮吞噬输入，没有穿透再选点。补充短按世界与拖动视角通过。
- 最大 64×128×64 读取、网络传输、存档回读全流程约 **24.91 秒**，共扫描 524,288 格，得到测试世界中 16,389 个非空气方块；完整核对 16,384 个地基层方块，以及另一角的草方块和顶层空气。耗时仅代表该电脑、该世界的一次测量。
- 最大区域读取取消通过；全过程编辑器对象保持同一引用。界面关闭时仍能完成读取与新配置存储。
- 已查看真实 HUD 截图，修正“重选”背景比例和地面边界线重合；冷启动验收错误日志为空，原生断言检查为空。之后临时事件追踪脚本使用了未绑定到系统的方法，产生诊断回调 AttributeError；已卸载这些追踪回调，产品源码中没有这些方法或注册。
- F11 是 Windows 原生触屏模拟，尚未在实体安卓手机上验证。本轮没有进行多个真实客户端的联机测试；身份与玩家状态隔离有离线回归覆盖。

运行脚本：`tools/verify_world_tools.py`、`tools/verify_world_capture.py`。须设置当前受管实例的 `MCDEV_SESSION_FILE` 和 `MCDEV_OWNER`；脚本只用于独立开发世界。`tools/generate_tool_items.py` 可以重新生成物品与 HUD 背景贴图。
