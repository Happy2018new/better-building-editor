# 大范围建筑实现与验证

2026-09-18。支持 X/Z ≤ 256、Y ≤ 384，最大 25,165,824 个位置。大范围沿用原有工具和撤销接口。

## 数据与任务

- `BlockStore` 按 16³ 分块：空气省略，均匀分块只存材质索引，混合分块使用 4096 个 uint16。全部混合的原始体素数组最多约 48 MiB，不含 Python 对象、调色板、历史、原生模型与引擎本身的内存。
- `Selection` 使用每块 4096 位的位图，整区全选不创建 2516 万个坐标元组。材质总数、非空气数量、图层计数随编辑维护，界面查询不扫描整区。
- `EditJob` 在副本上处理，原数组按写入复制。每步目标 6 ms；复杂工具以 128 格或一列为最小工作单元，个别工作单元可能超出目标预算。成功后发布一次；取消或越界失败保留原草稿。锁定层与工具参数取任务开始时的快照。
- 撤销记录最多 50 步、估算 64 MiB 预算，至少保留最近一步；估算不是进程 RSS 上限。全区随机纹理、连通填充等依然可能耗时较长。

## 预览与投影

- 小草稿保留原来的双缓冲原生预览。大草稿总览最多 6144 个代表方块，每块选择主要非空气材质；这是导航总览，不能表达每个细小孔洞和材质细节。
- 点击总览、使用“精细”按钮或输入精细视图中心，可进入最大 32³ 的真实方块区域。射线命中和轮廓使用文档坐标，支持远端与地下编辑；选取单格不会不断重置预览中心。
- 图层列表每页 16 行，二维画布仍每页 12×12。
- 大范围世界投影保留附近最多 32 个 16³ 精确分块，离开后撤掉演员实体，靠近再加载。生成时冻结建筑与显示条件，更新按钮重新取快照。
- 原生 `CombineBlockPaletteToGeometry` 调用本身不可分帧；以受限模型大小降低单次成本。当前 SDK 未找到模型释放接口，长时间不断创建不同几何体仍可能积累引擎缓存；本轮不宣称任意材质、任意连续编辑时长都有固定内存或帧率保证。

## 存储与网络

- v1 小配置继续兼容；v2 是调色板加压缩分块格式，每个混合块校验解压长度、校验和、材质索引和边界。重复块和不完整数据拒绝发布。
- 本地大配置以 v3 小索引与独立分页保存。每页最多 8 个传输包，分页在计时器中逐步写入；索引最后提交。删除后逐页清空数据，编号单调递增，避免延迟清理覆盖新配置。SDK 没有删除配置接口，清理后保留小的空配置文件。
- 上传使用递增序号和逐包确认，冻结数据后发送。每包最多 64 个均匀块、4 个混合块，并受约 16 KB 数据预算限制；包头和 JSON 字段开销另计。捕获也按包返回，客户端仅在接收完整文档后替换草稿。
- 服务端使用引擎身份，限制一个玩家一个任务，上传空闲 60 秒超时。读取或写入遇到未加载方块时通过 `DoTaskOnChunkAsync` 等待区块。
- 世界操作保留完整预检、冲突检查、保护检查、分批写入和失败回滚。日志每 1024 条压缩，避免数千万 Python 元组常驻。日志当前仍在内存，不能提供游戏崩溃或进程终止后的持久恢复保证。

## 验证范围

`python -X utf8 -m unittest discover -s tests`：75 项通过。新增覆盖最大体积填充/撤销/重做、紧凑选区、混合块序列化、压缩损坏、原子取消、层锁快照、工具边界、分页保存/载入失败、分包顺序、上传超时/取消、惰性世界预检、投影快照及生命周期、重启后原生 UTF-8 中文标题与固定精细中心。

`tools/verify_large_editor.py`：真实游戏 Python 2.7 中，最大尺寸填充、撤销/重做、精细视图、坐标 `(255, 383, 255)`、直接擦除、取消全区随机混合、保存/载入，以及大范围投影启停通过。填充约 2.5 秒，包含脚本界面等待，只代表均匀材质快速路径。

`tools/verify_world.py`：真实开发世界 27 格检查、上传、写入、撤销恢复通过。`tools/verify_entry.py`：真实 P/F6/F7 入口及捕获分包回传通过。没有进行 2516 万格实际世界写入，不能把草稿基准当成世界写入速度。

诊断报告、Tracy 采样与截图位于忽略的 `.runtime/`；没有向资源包添加图片或字体。

固定 1920×1080 客户区，最大尺寸均匀草稿，10 秒 Tracy 采样、动画开启：页面切换 578 帧（57.8 FPS，`cap-20260918-182430-66c80f`），总览拖动旋转/滚轮缩放 590 帧（59.0 FPS，`cap-20260918-182548-2d52bc`）。采样期间没有剪贴板查询；结果只代表当前开发机和这两个场景。

最终精细视图旋转/缩放采样为 574 帧（57.4 FPS，`cap-20260918-183431-5c5c13`）。实际重启游戏后，大配置能从分页存储重新载入；固定精细中心经真实三维擦除检查通过。总览提示复用已有字形，截图 `large_overview_final.png` 已打开检查。

`tools/verify_ui.py` 原有完整工作流 17 项回归通过。额外在游戏中确认 X=257 的新建请求被拒绝、384 高度配合 Y=64 世界原点被拒绝，编辑器保持可用且没有写入世界。

`tools/benchmark_large_storage.py` 额外验证全部 6144 个分块均为混合材质、25,165,824 个方块的编解码与写时复制。体素数组 48 MiB，分块存储估算约 48.75 MiB；宿主 Python 3.13 进程 RSS 约 99.8 MiB，解码 2.10 秒、编码 0.49 秒。这个 RSS 包含测试输入与编码输出，不代表游戏总内存；耗时也不能替代网易 Python 2.7 的游戏内基准。
