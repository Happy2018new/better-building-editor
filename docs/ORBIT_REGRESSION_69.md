# 旋转分块闪烁回归修复（阶段 69）

2026-09-23。用户提供回归范围为 `882f44f377f24b522486901ab98b240927f4f2ea` 及之后；表现是旋转时分块闪烁、缺块，随后逐块补回来。

## 提交对照与原因

- `882f44f` 修改静态文字缓存、选项控件保留、Primitive props 刷新和布局量测；没有改动 Scene、PreviewBuffer 或模型构建。`59e5623` 进一步修改原生提交与量测。
- `ef14a86` 为移除违规 `gui` 内部路由拦截，把模型层级更新改为 `PendingLayers`，每帧最多 4 个 `SetLayer`。同一帧里所有模型姿态已更新，层级却可能用 26 帧才能完成一批 104 个更新，因此会混用旧远近次序和新姿态。前移的裁切距离也通过旧层级传递，受相同延迟影响。
- 暂时将 `widgets.py`、`layout.py`、`primitives.py`、`reconciler.py` 写回 `882f44f^`，保留合法的当前数据层/SDK 实现，仍复现棋盘状错位。该对照**不是整个旧版基线**，不能由此宣称用户观察到的所有早期问题均始于 `ef14a86`；它确认了当前缺块现象的一个直接原因。
- 关闭 `SetLayer` 的强制刷新仍复现。一次更新整批层级可消除逐块补回，但出现约 205–245 ms 的 Python 帧回调峰值。因此最终没有采用仅把队列改为整批执行的方案，也没有恢复违规内部模块。

以往只检查 `tiles.builds` 没有增加、角度在改变，不足以验证连续显示正确。本次补充连续截图、跨分块遮挡像素、裁切后的像素以及持续触控期间的多段角度检查。

## 最终实现

1. 每个 16³ 分块和双缓冲模型使用固定的原生层级，不再在旋转、缩放、平移、前移或后移时排队重写分块层级。删除 `PendingLayers`。
2. 在每个分块模型前用已有透明纹理的 1 像素 Image 传递该分块相对观察平面的距离和生物群系编号。使用公开 `SetSpriteColor`，不更新原生输入路由；alpha 继续继承工作台淡入淡出。复用现有资源，没有新增图片。
3. `preview_depth.py` 使用 16 位定点距离，精度 1/64 格；每个分块在顶点着色器内加入自己的局部深度。全部分块共用同一个深度映射，遮挡与裁切在同一帧生效，不依赖分块绘制次序。
4. 固定绘制层级最高 304，低于亮度遮罩与框线。每张状态图片紧邻对应模型；双缓冲中间容器的层级显式为 0，避免父层级累加改变状态/模型次序。
5. 生物群系成为模型状态缓存键的一部分，改变染色只更新状态颜色，不重建几何。保留精确方块、局部编辑、模型预热和双缓冲。世界透视投影分支保持原行为。

三轴方向指示器仍使用少量公开层级更新，触屏按住时延至释放；模型已不依赖这一路径。
