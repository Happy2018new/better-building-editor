# R29 两库私有适配器与来源准备

主程序尚未切换依赖。本包保存两个私有适配器、七个调用方补丁及来源工具补丁的原件、双解释器控制和 root 独立重放结果，供下一轮直接审查。固定库版本、接入边界和截止见[迁移计划](../../REPOSITORY_SPLIT_AND_MIGRATION.md)。

运行补丁 SHA256 为 `670a7982ea9b65eb8174aca71f8ffafd07d1e67a4e4d50e71738f53cbdfd59df`；三工具补丁为 `cfa430d1ba4b47793d760ee75f4a3d01331ed27c9e82c4fc90597ad0932c0700`。后者基线为完整 `7021e32cb64f09b9567c55a4c7fad3800afc4cc0`，保留新版 error_text 和所有既有模块。旧候选目录原封保留。

真实 Py2.7.13／Py3.13.13 各验证54份完整 Document、66,249次布局调用及四个实际调用方纯准备；root 在物理独立副本重复同一控制。来源工具的实际 CLI 拒绝漂移、缺文件和旧快照遗漏；book 对缺声明文件的处理从静默省略改成明确拒绝，这项行为变化及相应 fixture 工作未隐藏。工具驱动首次 Windows stderr 解码失败的原件也保留，没有把候选工具改成吞错。

`index.json` 引用25份原件、去重为23个确定性 gzip 对象，共142,400字节（不含本说明），最大对象50,382字节。按 references 中的原 SHA 定位 objects 中的文件；解压后核对原 SHA 与长度。打包时逐件解压并与原件核对。

这些是私有候选的纯逻辑和来源控制，不是主程序接入、原生画面或新源资格。主仓 metadata、两个库和人工接受记录没有改变；新增人工关闭0。
