# 附魔台原生本体偏移测量

2026-10-15，NEMC 3.10.0.420447。36帧四方向测试已完成并恢复原方块、相机、玩家位置和环境。此证据只确认本体问题及补偿量，尚未接入产品。

真实附魔台、直接native palette、Serialize/Deserialize roundtrip、prepare后的palette使用相同相机和同一支撑块。三种投影路径都比真实附魔台低0.125格；这会使底面插入支撑块并产生交错细线，也会改变书和台面的相对距离。它和后方真实树叶选框穿透书封面的黑线不是同一原因。

进一步将本体与支撑分开生成，保持支撑不动，对本体施加0、0.0625、0.125、0.1875格的Y偏移。0.125恢复原生位置；0.0625不足，0.1875过高。四个方向红色台身纹样的原位IoU分别为1.0、0.9980、1.0、0.9774，最佳图像平移均为(0,0)。原始路径的最佳平移为(0,-27)屏幕像素。分析器没有移动图像来获得通过分数。

工具：`tools/probe_native_palette_body_r16.py --body-offsets 0 .0625 .125 .1875`；`tools/analyze_enchanting_body_r17.py`。`report.json`保留完整回执，`analysis.json`保留测量，`crops.json`关联原图／裁切SHA256。图片只是精确裁切，没有增强。完整原图保留在报告记录的本地`.runtime/enchanting-body-offset-r17-v1`。

后续实现应在独立本体的渲染适配中处理，不修改文档位置、NBT、支撑块或书的pivot。不把此处世界本体的四向位置检查冒称为编辑器／full／missing整体书外观资格。
