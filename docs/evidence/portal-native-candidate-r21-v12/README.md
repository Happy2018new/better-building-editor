# Portal v12 Six-Image Offline Review Package

This package preserves the last cold normal-TIME native candidate attempt for
End gateway and End portal. It is an offline evidence replay, not a game launcher.
The original six PNGs remain the visual evidence. The root agent independently
opened all six images and accepted only their narrow visibility.

```
python -I -B -X utf8 replay.py --verify .
python -I -B -X utf8 replay.py --verify . --frozen-project PATH_TO_ORIGINAL_FROZEN_V12_PROJECT
```

The first command uses only Python's standard library. It checks every payload
hash, parses all original PNG bytes and CRCs, reconstructs RGB pixels, recounts
the four world-view portal interior masks, and replays the reports, capture
receipts, load documents, restoration, memory boundaries and exact exit records.
The masks were generated offline from the preserved native camera face points
with the original polygon/MinFilter(11) algorithm. This does not establish native
appearance equivalence. Editor images have visual review but no interior oracle.

Portable replay verifies all 3,692 snapshot manifest entries and their canonical
digest, plus actual bytes of the selected frozen source and all 17 committed
portal source paths. Commit bytes and actual frozen bytes are separate; their
differences are explicitly recorded in source-binding.json. The four portal
aliases and dedicated shader/mesh/texture contents are compared across them.
It does NOT claim the omitted full runtime project bytes
are present. Only --frozen-project hashes all 3,692 original actual files again.
The complete project was independently hashed after finalization and while this
package was built. The selected source subset includes the full recorded host
import closure and the two separately frozen missing dependencies.
