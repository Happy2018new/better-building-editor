# T02 existing originals show a small button contribution

This is a narrow offline comparison, not another source/resource audit or a new MC run. No acceptance gate is changed and no issue is closed.

R27's actual full/single/full submissions already used the same native volume `(16,16,10)` and stone-button aux 0 at index 827. Full/A2 included stone at index 1083; single did not. Therefore a new same-volume button-only experiment would repeat that control. R28's Y+4 experiment drew support only; its measured displacement says nothing about a button being drawn during the shift.

The existing R28 combined baseline and support-only original are **not identical** inside the shift diagnostic's original ROI `[577,242,714,452]`. They differ at 264 pixels; 82 exceed a maximum-channel RGB difference of 12, with maximum 22. Every difference is in `[626,365,665,403]`. All 82 stronger pixels fall inside the old R27 single-button silhouette (758 pixels, bbox `[626,365,665,402]`). Both existing repeatability controls are exact: combined baseline equals the original source restored, and support-before equals support-after, inside that ROI. The same small difference therefore repeats at both endpoints.

This weakens the claim that the combined model produces no button output. It is consistent with a small, low-contrast button blending with the supporting stone face. It does not establish correct mounting, thickness, native depth behavior or agreement with vanilla. The metric here locates a contribution; it is not a new visibility pass threshold. `analysis.json` binds original hashes and the exact actual R27 inputs; `analyze.py` reproduces only these comparisons. `comparison-4x-nearest-derivative.png` is plainly labelled as a crop magnified 4× by nearest neighbor, alongside unchanged original files.

If another MC discriminator is justified, change only the support material at index 1083 from stone to opaque white concrete, leaving the stone button's index 827/aux 0, fixed native volume, flags, camera, slot and layout unchanged. Compare each combined model with its matching support-only model. White support provides contrast while retaining a full opaque cube beside the unchanged button. A clear button against white helps separate the visual-contrast hypothesis from continued combined depth/culling work. Native material changes may also influence lighting/culling, so it remains a bounded discriminator and requires review; it is not a reason to mark the issue closed.
