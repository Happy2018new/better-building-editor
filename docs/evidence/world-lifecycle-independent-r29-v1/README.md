`af9c628c` 在每个写入批次前检查玩家是否在线以及是否仍在原维度，发生变化或查询失败时停止后续批次、释放任务并保留已写入前缀。沿用原用户要求：只在开始时检查写入权限，单格失败后继续，不回滚；不新增逐格权限检查。

真实 CPython 2.7.13 与 3.13.13 各运行 21 条实际上传、WorldJob、server.tick、reply 和 client.receive 对照。修前各有两条在线查询异常逃逸、旧任务及客户端等待残留，只有 19/21 条能继续新请求；修后无逃逸，在线客户端等待清空，**各 21/21 条均在同一 host 上真正发起并完成后续新请求**。

涵盖首批前及写入一格后的换维度、没有离开事件的离线、在线查询和维度查询的 SDK 字节异常，以及显式取消、离开事件、正常完成、首格失败继续和首格失败后取消。四种权限变化继续原任务属于既定行为，不作为新漏洞或待办。已确认离线时不发送最终回复；在线分支只发一次，迟到进度不能恢复等待。
