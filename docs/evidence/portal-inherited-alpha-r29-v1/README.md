# 末地原生候选：界面继承透明度的私有补修

默认legacy预览会在正交UI中乘CURRENT_COLOR.a，opt-in native片元包装层却只读投影透明度。私有候选在同一检测条件下乘入继承透明度并在零值discard，保留One／SourceAlpha清屏及星点混合、世界路径、原生纹理、TIME、网格和参数。没有安装到产品或冻结副本，也没有切换默认末地效果。

第一组180次WebGL2实际混合采样全落在黑纹理。独立审查指出其未覆盖星点RGB；原脚本／结果保持，仅解释为清屏层与世界路径保持证据。之后另做54组非黑纹理像素中心阳性控制：45组实际产生彩色星点，9组零贡献恰为UI fade0。最低正贡献有效透明度为.125×.5=.0625，避开只靠饱和结果判断。候选所有像素均等于未改片元外部传入有效透明度的oracle；旧片元16组有差异。世界透视与fade1输出逐像素不变，GL错误0。

16个实际编译／链接配置中10个通过，6个GLES100 skinning配置保留安装基线同样的mat3x4顶点头不支持，不能说全部native variant通过。候选生成器实际生成同一片元，只有这一个资源变化；contract明确不再称“只改include路径”。16份shader／include身份已记录。
