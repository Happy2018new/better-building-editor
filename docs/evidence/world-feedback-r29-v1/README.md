# R29 错误反馈原件

本包保存两处可复现Python2错误的修复前后记录：SDK字节异常使写入任务无法发最终回复，以及公开“应用到世界”被安全拒绝后中文原因无法显示。行为与验证范围见[专项说明](../../verification/WORLD_FEEDBACK_R29.md)。

`index.json` 引用10份原件，按原SHA256确定性gzip去重为9对象；保存原长度、压缩长度、压缩SHA，打包后解压逐字节核对。共15,871字节（不含本说明），不携带游戏副本或历史大图。

修复前报告及候选v2报告来自 `.runtime/r29-world-feedback-candidate/`；root独立报告来自 `r29-world-feedback-root-v3/`，实际导入的是主仓集成后的源码。root报告保留驱动原字段名 `expanded-current`，含义是驱动对当时实际主源码的取样；不能凭字段名将它错认成修复前报告。索引的三个实际产品SHA区分其来源。

候选v2的独立控制为18条反馈链与20个编码控制。root实际主源码另重放18条链，候选专用helper控制字段为null，未冒称重复执行。正式5项永久测试和67项定点执行见专项记录；它们的工具输出没有被改写为本包原始日志。

验证通过的是CPU消息语义及JSON序列化边界。ModSDK网络、原生输入、界面文字像素和用户人工接受仍待；新增人工关闭0。
