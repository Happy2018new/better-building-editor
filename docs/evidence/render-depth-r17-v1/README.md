# 后方真实方块选框穿透自定义表面

2026-10-15，NEMC 3.10.0.420447；第十七轮独立调查。用户指出横穿书封面的黑线与后方树叶有关。

## 已确认根因

书继承的原生 `entity_for_skeleton_alpha` 具有 `Blending`、`DisableDepthWrite`。后方真实方块被准星选中后，后绘制的原生选框可以覆盖前方未写深度的书。树叶不是唯一触发材质：石头与玻璃均能复现。开启深度写入后选框被正确遮挡，同时书封面能够遮住它内部的页体。

独立 atlas 黑留白采样错误已经另行修复；不能把那项修复当成本报告黑线的解释。

## 有效对照与自动检查

所有有效对照都在冷启动前同时注册 depth-off / depth-on 模型与材质，随后在同实例、同相机切换；诊断 shader 使用固定时刻，air 重复采帧证明目标区域稳定。真实前／后方块及玩家位置在 finally 恢复。准星回执必须明确选中对应后方真实方块。

| 目标 | 深度关闭时，树叶／石头／玻璃引起的内部变化像素 | 深度开启时 | 结果范围 |
| --- | --- | --- | --- |
| 旧书模型 v7 | 21 / 21 / 21 | 0 / 0 / 0 | 棕色不透明封面内部；自身页体穿透另由截图确认 |
| 新铰链书候选 | 16 / 5 / 5 | 0 / 0 / 0 | 深度关闭时页体错误遮住大部分封面，可用封面区域变小 |
| 末地折跃门 | 250 / 231 / 231 | 0 / 0 / 0 | 固定星点时刻，不透明表面中央矩形 |
| 无背板展示架中的钻石剑 | 17 / 29 / 未测 | 0 / 0 / 未测 | 半砖平台降低视线，使后方选框确实穿过剑身 |

像素变化阈值为任意 RGB 通道绝对差大于 8。所有 air 重复帧在检查区域均为零变化。`book-old`、`book-hinged`、`end-gateway` 保存原始截图的精确裁切、全图 SHA256、裁切 SHA256、掩膜、选择回执与分析结果。裁切没有重绘或增强。必须同时保留能复现错误的 depth-off 对照；没有复现、准星未命中、重复帧不稳定、截图不可靠均不能判为修复通过。

复现入口：`tools/prepare_depth_controls_r17.py`、`tools/probe_projection_occlusion_r17.py`；分析入口：`tools/analyze_projection_occlusion_r17.py`。来源分别是公开蓝图 `test.dynamic.special` 和 `test.dynamic.portals`。书 ROI 为 `[920,495,1065,635]`（棕色封面掩膜），折跃门为 `[900,450,1080,690]`（不透明内部矩形）；重新取图后必须重新确认 ROI 处于目标内部。

完整本地捕获：`.runtime/depth-book-paired-r17-v4`（20帧）、`.runtime/depth-hinged-matrix-r17-v1`（100帧）。两者均 completed/restored。旧热重载实验 `.runtime/book-depth-{off,on}-r17-capture-v1` 未刷新 shader，因此无效；不得复用其材质结论。

## 其他材质与未完成边界

`tools/audit_render_depth_states.py` 解析实际安装版本的原生／项目材质继承、states 增减和 variants。当前 75 个项目材质均能解析。该清单是版本升级审查工具，不是像素验收。水、物品图标、锅内表面也继承关闭深度写入，不能因此直接断言都受影响或全局切换它们。

满锅岩浆、细雪、水的低角度表面对照使用真实半砖选框，48帧测试 completed/restored；本次表面内部未复现穿透，原生锅体可提供遮挡。普通青色混凝土、原生箱子、紫色潜影盒、刷怪笼标识和带实心背板的展示框也未复现。真实采样旗帜的正面在 `.runtime/depth-banner-sampled-r17-v1` 可见且未发现穿透。早期告示牌／旗帜朝向侧面或没有有效actor的图不能用于其外观验收；这些结果也不代表全部状态与相机方向的穷尽证明。

无遮蔽物品首次对照未让选框穿过剑身，因此不是有效负控；降低玩家到半砖后才复现。`shelf-item` 保存有效对照，来自 `.runtime/depth-shelf-low-platform-r17-v1`，ROI `[950,530,1040,620]`，蓝色剑身掩膜腐蚀3像素，树叶／石头选择回执有效。450张当前flat-icon贴图只有0／255 alpha，修复允许可见像素写深度，透明孔洞仍由fragment discard保留。

修复显式移除书、末地表面、flat-icon及旧剑材质继承的 `DisableDepthWrite`，共12条；水和锅材质保持原状态。末地表面已在最终资源名冷启后完成31帧编辑器和28帧world回归，逐张检查11张review sheet，覆盖full／missing、透明度0／0.45／1、占用隐藏与恢复、旋转／镜像、图层和切面。新的生产证据在 `../portal-product-r16`，默认编辑器实际没有注入候选。四组已启用渲染来源校验通过。

书和物品仍未授予生产资格。书铰链模型v3修正了讲台90°方向和页体自遮挡，但新冷启的原生对照发现薄封面深度冲突细点，以及待核对的附魔台本体／书相对高度；不能把选框穿透修复当作整体外观完成。
