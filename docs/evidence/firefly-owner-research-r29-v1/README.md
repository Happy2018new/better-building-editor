# OB-01 独立飞虫：来源与最小接入探针准备

本包保存实际3.10原版粒子／材质／着色器来源、MCP依据、私有纯坐标候选和最小绑定探针。**没有启动或连接MC，OB-01仍开放；没有原生创建、UI绑定、shader引擎编译或像素通过。** 灌木已有flipbook不是本包新增实现。

原生firefly每个瞬时发射器产生1只粒子，寿命10—15秒，普通alpha混合，颜色与运动数据可直接取得。9386份实际data JSON中没有找到灌木的频率、发射体积或环境调度。官方PaperDoll粒子示例使用网易特效，不能据此断言微软firefly能进入UI。下一次最短分岔是独立世界创建／移除对照，再在独立UI root carrier上尝试绑定并核位置、隐藏、裁剪和世界逃逸。

58份原件映射为54个gzip对象，见`index.json`；先核stored SHA，解压后核raw SHA，再按`references[].path`恢复。原始`README.md`和`RUNBOOK.md`均作为对象保留，含具体操作卡与边界。17个实际payload在真Py2编译、生命周期模拟在真Py2／3通过；它们仅是离线准备。

探针只允许归属明确的本项目私有冷副本，不选择任意运行中的MC；安装器只改私有副本，不改产品源。恢复后应先阅读原RUNBOOK并核实际工具／来源绑定。部分脚本保留原`.runtime`相对路径假设，解压文件本身不意味着已安装或可在任意目录运行。用户另一独立对话、另一模组的MC禁止操作。
